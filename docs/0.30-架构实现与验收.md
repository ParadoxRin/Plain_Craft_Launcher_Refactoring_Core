# PCL Mac 0.30：默认资源浏览器与账户、皮肤 Host 迁移

日期：2026-10-25。依据当前 v1.3 架构规范，延续 v1.2 的边界、生命周期和证据要求。

## 实现范围

- ResourceBrowser（含 WindowsResourceLayout）、SkinManagerWindow、AccountToolsWindow 的签名、字段、IL 和生成的异步状态机纳入 Contract-only 符号守卫；页面不再持有 ResourceCatalog、AccountManager、认证服务或皮肤写入器。
- 默认目录的分类、搜索、分页、版本与加载器筛选、项目说明、更新日志、已安装资源名称格式由 Host 查询并转换为展示 DTO。图标使用私有选择句柄、HTTPS 来源限制、长度限制及已校验 blob 导出；页面负责渲染和取消自身图片任务。
- 离线账户索引、创建、选择、退出、移除，以及玩家名皮肤获取、保存、刷新、预设、导入、移除和导出由 Host 执行。主窗口仍保留旧展示模型，相关写入已通过同一工作区接口。
- 微软外观的解析凭据、皮肤与披风操作、图片读取迁入 Host，并共享现有 AccountManager；没有复制另一套登录会话。保留原设备授权、钥匙串、正版验证和游戏进程机制。
- 外置认证的发现、登录、选择角色、凭据保存、退出与纹理操作复用原实现。密码经一次性内存句柄传入；挑战最多 8 个、10 分钟过期，Host 重启后重新登录。收据只含公开资料和不含凭据的句柄，不写入密码或令牌。
- 图片导入先校验、规范化再保存，刷新失败不覆盖旧皮肤；已获取的皮肤句柄绑定账户。只有明确登记的读取可以安全续做，未知提交状态的写入仍拒绝盲目重放。
- 修复关闭竞态：正常退出先取消并等待会话重连监视器，避免旧监视器在 Host 退出后再次建立连接，干扰新会话；游戏托管与独立运行沿用原 Host 策略。

首次最终包的重启检查在连接握手处失败；旧记录 `release-host.json` 保留。已修复关闭监视器的竞态，连续重启与完整流程均复测通过，最终结论使用 `release-final-host.json`，不是重命名失败结果。开发期 27 项/17 项报告不替代上述最终结果。

微软测试后仅修改了 Client 关闭逻辑和 Desktop 内嵌功能矩阵；`microsoft-host-code-continuity.json` 确认 Host 可执行文件及 184 个 DLL 与获准读取钥匙串的被测版本一致。最终客户端变更另经界面、重启、托管和独立运行测试。

`tested-code.json` 固定最终被测的 397 个 DLL 与 Host 可执行文件哈希。交付前只更新内置报告和外层签名，核对代码未变化；ZIP 解压逐文件核对、签名与 SHA-256 记录在 `delivery.json`。构建仅保留既有 MainWindow AVLN3001 提示，没有新增编译错误。此次没有将历史全功能状态一律重置为已验收。

## 保留的边界和限制

- Desktop 仍引用 Core：主窗口旧展示模型、联机等旧页面及 Bootstrap 桥接继续迁移，未删除兼容写入授权，不宣称全功能或全部程序集拆分完成。
- 未提供真实外置认证账户，不声称完成真实外置服务器登录、角色选择及纹理上传；测试将验证失败路径和密码不落盘。未提供 CurseForge 密钥，本轮不测试其带密钥 API。
- 不主动修改用户的在线皮肤、披风，不注销或移除用户微软账户；微软只读及启动结果单独记录。
- 托管游戏测试的主动终止不等于正常菜单退出；渲染器初始化不等于玩家进入世界、保存与重进。
- Apple Silicon 自包含包使用本地 ad-hoc 签名，未进行 Developer ID 公证。历史包和证据保留。
