# PCL Mac 0.20 · Windows 界面对照版

本版用于和 Windows PCL2 2.99.0.0 对照功能位置。旧版 0.19 的应用和 ZIP 保留；不是宣称所有 PCL2 功能已完成或像素完全一致。

## 新入口

- 顶栏：启动 / 下载 / 设置 / 更多。
- 下载左栏：原版游戏 / Mod / 整合包 / 数据包 / 资源包 / 光影包，顺序、文字与图标来自原版 XAML。
- 启动：左侧账户和底部启动按钮，右侧主页、当前版本与运行记录。
- 下载资源：名称、来源、版本、类型筛选；整行项目列表；点击项目进入独立详情；返回后保留原搜索结果。
- 详情：项目介绍与官网 / 百科 / 复制名称，版本筛选、版本与加载器分组；点击文件显示已有安装、另存为、更新日志等操作。
- 设置：启动 / 联机 / 个性化 / 其他，保留原版卡片、输入控件类型和顺序。
- 更多：帮助 / 关于与鸣谢 / 百宝箱 / 反馈 / 新功能投票。Mac 独有入口集中在 Mac 扩展。
- 更多 → 功能对照：内置 132 项现有矩阵，支持搜索和只看未完整验收；保留实际缺口与证据状态。

## 明确的差异

设置页灰色控件属于对照占位：尚未逐项绑定，不能把占位当成对应功能已实现；可用上方“打开对应设置”进入原有工作台。百宝箱、反馈与投票也明确保留未接入状态。模组管理、实例管理、下载操作等已有辅助窗口暂时沿用 Mac 布局。

此版下载目录默认 Modrinth；选择全部或 CurseForge 后，通过现有工作台完成相应搜索。将多源结果直接呈现在新原版布局中仍待迁移。无内置 CurseForge 密钥。

原版标题栏动画、字体度量、窗口装饰和所有自定义控件模板尚未逐像素复刻。当前是页面结构与功能位置对照版，不能称为完整的一比一 UI 移植。

浏览“全部版本”不会改变安装目标。安装仍检查当前实例游戏版本与加载器；不兼容文件只可另存为或改选匹配实例。所有下载和安装继续免登录；离线身份与微软登录沿用原核心。

## 来源与复现

原版源码：PCL 2.99.0.0，提交 6b9a50df911c9d68b69b24c979efba477fb14b67。
对应 Windows 虚拟机截图见项目输出 `pcl-windows-ui-capture/final`。
`scripts/build-windows-layout.py` 只读原版 XAML，生成 `docs/windows-layout-baseline.json`；新应用将清单和功能矩阵内嵌，移动应用后仍能查看。

运行 `--acceptance-windows-layout --data-root <独立测试目录>` 可实测原版分组、真实联网搜索、项目详情、文件选择、返回、账户模式和所有新导航入口。它保存实际 Avalonia 窗口截图和 JSON 记录，不注入搜索数据，不启动游戏。

需要回到上一套 Modern UI 时，在启动参数中加入 `--modern-layout`。已有数据仍使用原数据目录，且保持同目录单实例锁；并行对比请给测试版指定独立 `--data-root`。

## 本轮验证

215 项核心回归与最终自包含应用的 27 项真实窗口检查通过；包括离线账户保存、微软模式控件切换、真实模组/光影搜索与文件操作入口。ZIP CRC 与解压后 ad-hoc 签名检查通过。本轮未重新执行微软 OAuth、游戏启动或进入世界测试。运行回执位于 artifacts/release-verification-0.20.json。
