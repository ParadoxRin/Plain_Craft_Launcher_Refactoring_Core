# 账户登录与免登录下载（0.6）

日期：2026-10-23。Minecraft 1.21.1 / Apple Silicon。

用户确认本轮优先级为“不登录账号也能下载安装”，不是在没有网络时获取新文件。此流程已接入界面并实际验证，不需要微软应用 ID。

## 无需登录即可下载

点击主页“安装 / 修复”即可下载 Java、游戏、库和资源；“安装加载器”和左侧模组、光影、资源包、整合包入口也不要求先登录微软。下载服务与账户解析分开，不以微软 token 解锁公开下载接口。下载本身仍需网络，已有正确缓存按大小与哈希校验后复用。

本轮在只有离线账户、没有微软账户的环境下，实际搜索 Adrenaline，移开此前缓存后重新下载官方 `.mrpack`，校验 SHA-1，并检查其现有独立实例；另外首次下载并安装 Mod Menu 到普通 Fabric 实例。没有将这次缓存检查表述为重新下载整包所有模组或全量游戏资源。

## 离线登录

主页账户模式选择“离线登录”，输入玩家名后点击“使用此名称”，或直接点击“启动游戏”。名称、历史和上次选择保存，下拉框可切换；“移除账户”删除该记录，不删除存档或游戏。

名称按照 PCL2 对 1.21.1 的约束：修剪两端空白，1–16 个 UTF-16 字符，不能有英文双引号或控制字符。中文名称可以保存；联机服务器或模组可能有更严格的名称规则。

UUID 复用 PCL2 `ModLaunch.McLoginLegacyUuid` 和 MeloongCore 的稳定哈希算法，保持同名身份稳定。该算法不同于部分启动器的 OfflinePlayer/MD5 算法，已有其他启动器存档应注意玩家身份差异。默认 UUID 路线已迁移；自定义皮肤、正版名称映射和皮肤性别 UUID 调整尚未迁移。

离线会话 user_type 为 legacy，不带 `--demo`；“试玩”仍是独立按钮。离线身份可以启动本地游戏，不产生微软授权，不能据此登录要求正版验证的服务器或使用微软在线服务。

## 微软登录

选择“微软账号”，填写已获准用于 Minecraft 的公开 OAuth 应用 ID，点击“登录微软账号”。在系统浏览器授权；页面显示设备码并支持复制。程序不收集微软密码或 client secret。用户本轮不提供应用 ID，所以当前没有真实微软账号授权验收。

实现沿用 PCL2 的设备码授权 → Xbox Live → XSTS → Minecraft token → 权益与玩家档案；支持等待、slow_down、拒绝/过期、儿童账户或 Xbox 档案错误提示。已保存账户可切换，启动时复用未过期会话或刷新授权；授权失败要求重新登录，不自动变成离线身份。

勾选“记住登录”时，仅 OAuth 刷新令牌通过 Security.framework 保存到此应用、此数据目录作用域的 macOS 钥匙串。游戏访问令牌留在内存；accounts.json 只保存账户类型、玩家名、UUID、公开 client ID 和选择状态。钥匙串失败时可以保留本次会话，不回退明文保存凭据。系统可能要求确认钥匙串访问。

“退出登录”删除本地保存的刷新凭据并清除会话，保留玩家条目；“移除账户”还删除该条目。它们不会退出浏览器里的微软账户，也不会删除存档。“不记住登录”的账户重启后需要重新授权。

CLI：

```bash
# 下载与搜索无需账号
./.tooling/dotnet/dotnet src/Pcl.Cli/bin/Release/net10.0/Pcl.Cli.dll install --data-root runtime/apple-silicon-1.21.1
./.tooling/dotnet/dotnet src/Pcl.Cli/bin/Release/net10.0/Pcl.Cli.dll resource-search --kind modpack --query Adrenaline --data-root runtime/apple-silicon-1.21.1
# 离线账户
./.tooling/dotnet/dotnet src/Pcl.Cli/bin/Release/net10.0/Pcl.Cli.dll account-add-offline --name PCL_Mac --data-root runtime/apple-silicon-1.21.1
./.tooling/dotnet/dotnet src/Pcl.Cli/bin/Release/net10.0/Pcl.Cli.dll launch --offline-name PCL_Mac --data-root runtime/apple-silicon-1.21.1
```

也可 `account-list`，或 `launch --account <id>`。微软初次登录使用 `launch --client-id <公开应用ID> [--remember]`；不将刷新令牌作为命令行参数。钥匙串经原生 API 调用，不借助会在进程参数中暴露令牌的 shell 命令。

## 对照来源与验收边界

本地附件 PCL 2.99.0.0：`Pages/PageLaunch/PageLoginLegacy.xaml.vb`、`PageLoginMs.xaml.vb`，以及 `Modules/Minecraft/ModLaunch.vb` 的 McLoginLegacyStart/McLoginLegacyUuid、McLoginMsStart/MsLoginStep1New/MsLoginStep1Refresh。附件为参考材料，账户保存采用 Mac 平台实现。

微软协议按[官方设备码文档](https://learn.microsoft.com/en-us/entra/identity-platform/v2-oauth2-device-code)及[令牌刷新说明](https://learn.microsoft.com/en-us/entra/identity-platform/v2-oauth2-auth-code-flow#refresh-the-access-token)核对。

自动测试 54 项，包含离线 UUID 固定向量、名称校验、持久化/切换/移除、不触碰钥匙串或认证接口、非试玩参数；微软设备码等待与限流、模拟 Xbox/游戏权益/档案、刷新轮换、内存缓存、退出、授权失效和取消；公开下载无 Authorization 头。

实机：原版与 Adrenaline 均以 PCL_Mac 离线身份启动，运行检查完成图形和纹理初始化；测试主动结束进程，137 不是正常保存退出。没有进行本轮世界内游玩、正版服务器联机或真实微软账户登录验收。macOS 钥匙串用独立测试条目完成写入、读取、更新、删除，测试后清理，不使用真实账号凭据。

全套 PCL2 登录仍未完整对齐：皮肤管理、外置认证、第三方认证及真实微软账号回归留待后续。运行证据以 artifacts/evidence-0.6 为准。
