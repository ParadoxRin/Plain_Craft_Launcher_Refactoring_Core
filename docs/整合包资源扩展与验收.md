# 0.8 整合包与资源扩展

本文记录 2026-10-23 的 0.8 实现与证据。0.4～0.7 文档保留为历史记录；其中“仅 1.21.1”“不支持 CurseForge/HMCL/MultiMC/导出”等描述不再代表当前能力。它们的旧测试结果也不自动转为本版新功能的验收结果。逐项状态见 `status-resources-packs.json`，最终发行验收另见总报告。

## 实际入口

- Modrinth：模组、光影、资源包、数据包、整合包；当前实例版本/加载器过滤、分类、分页、中文别名、详情、更新日志、百科关联和另存为。
- CurseForge：独立官方 API 窗口，模组/光影/资源包/整合包、分页及版本。用户输入自己的 API Key，仅保存在本窗口内存。关闭窗口清除；没有 Key 明确提示缺少条件。
- 本地资源：扫描已有外部文件，分类/搜索、多选启停、备份移除、依赖检查、操作历史、更新检查和忽略版本。批量更新可多选目标，在副本内下载和验证后预览，再统一提交；原文件完整备份。预览后资源或清单发生外部修改，会停止提交。当前历史只记录本版本操作，不能补造过去记录。
- 数据包：Modrinth 选择版本后选择本实例的存档；本地资源中可导入 ZIP、启停及移至备份。存档必须包含 level.dat，不允许选择外部路径或链接逃逸。不会启动游戏或执行数据包指令。
- 整合包管理：识别格式、显示版本与文件、导入新实例、受限文件手动匹配、更新为独立副本、导出 .mrpack 以及保存/读取导出配置。

PCLCS 固定 WikiEntries 是中文别名和百科身份的来源。只有其明确列出的双平台 slug 才被归为同一百科身份；界面仍分别检索两个来源，尚没有全平台合并结果列表，不能称完整实现跨平台去重。名称相同不会被当作同一项目。

## 格式与迁移范围

| 输入 | 已实现 | 明确边界 |
| --- | --- | --- |
| Modrinth .mrpack | 官方索引、客户端环境、可选文件开关、SHA1/SHA512、overrides/client-overrides；vanilla/Fabric/Quilt/Forge/NeoForge 指定版本；多 Minecraft 版本 | 不支持多加载器混合；可选文件目前为整体包含开关，尚无逐文件选择 |
| CurseForge manifest v1 | Minecraft/加载器、文件 ID、overrides；官方 API 元数据和 SHA1/大小；缺失受限资源列表 | 自动联网安装需自己的 Key；无 API 手动匹配 JAR 只证明本地文件哈希，不能证明远程项目身份 |
| MultiMC formatVersion 1 | mmc-pack 组件、.minecraft 数据、嵌套实例根目录 | 自定义 patches/jarmods 明确拒绝；不迁移启动命令/JVM 指令/环境变量 |
| HMCL | modpack.json/gameVersion/minecraft 数据目录 | 自定义 versions 元数据明确拒绝；含模组但无加载器声明时需用户填入 |
| MCBBS | mcbbs.packmeta addons/overrides，已支持加载器映射 | OptiFine/LiteLoader 包组件未实现，不等同于独立组件安装能力 |
| 普通 ZIP / 带启动器 ZIP | 指定游戏与加载器，导入已知游戏数据目录，可处理 .minecraft 包装层 | 不执行 exe、shell 或包内命令，不导入启动器账户或任意自定义程序 |

ZIP 检查遍历路径、反斜杠、绝对路径、控制字符、符号链接、大小写冲突、单文件与解压总大小。安装在临时实例完成，失败不覆盖已有实例；不把运行包里的脚本作为用户指令。

升级需要首次安装的 SHA256 基线，分别识别新增、修改和用户删除。用户可选择在新实例中保留这些改动，原实例保留。没有基线的旧包会提示，不能猜测覆盖。这是文件级保留，尚不是配置结构的三方语义合并；旧模组保留后仍可能与新版冲突。

导出包含已选数据目录的当前实际字节，不依赖旧索引声称文件未修改。SHA1/SHA512 与 ZIP 写入在同一次流读取中完成；索引和导出收据随包保存。存档与游戏选项默认不导出；账号、令牌、日志、服务器列表和启动器状态按已知路径/名称排除。自定义 config 中任意私密值无法自动辨认，分享前仍应检查；嵌入资源的再分发许可由其作者决定，本程序不会自动上传。

## 依赖检查与 Mac 边界

Fabric 的 depends/breaks/provides 和嵌套模组参与安装、启停、移除及更新前检查。旧 Forge mcmod.info、Quilt、LiteLoader 可以识别和导入，但尚无完整的相应依赖约束分析。OptiFine 独立实例不作为通用模组加载器。

Forge/NeoForge 使用 Tomlyn 读取 TOML，处理声明的必需、可选、不兼容和不建议依赖；客户端 side、排序循环、Java/FML 范围、manifest 中的版本，以及 JarJar 中的模组。OpenGL 范围展示为运行要求，依实际渲染器确认。当前版本比较覆盖常见数值区间、精确范围、区间并集及预发布标记；尚未完整等价移植 Apache Maven ComparableVersion 的全部复杂语义。第三方 language loader、旧版依赖和特殊版本字符串不能据此宣称全部兼容。

批量更新将所有选中版本及其平台必需前置合并为一组，冲突时停止。先复制全部当前资源及验证上下文，再在该副本提交所有同类资源并核查本地声明；因此相互依赖的 A1/B1→A2/B2 可同时完成。下载/校验/依赖失败不触及原目录。提交前后再次比较快照，目录替换失败会恢复旧目录，期间出现的额外文件保留在备份中。进程被强制终止后的自动事务恢复尚未实现；保留的 rollback.json 供人工恢复，不能将异常关机称为自动回滚已验收。

光影保留既有 Mac 功能检查和实验提示。应用/撤销会备份 Iris 配置或 options.txt，并核对应用后 SHA256；游戏后来改动配置时拒绝直接覆盖，避免丢失用户设置。当前自动光影方案仍以 Fabric/Iris 为主。Iris 官方没有 Apple Silicon 驱动支持保证；先前指定 Complementary 组合的人工世界验收不能推及其他包。

## 证据分层

独立测试文件为 `tests/Pcl.Tests/PackResourceTests.cs`，由统一测试入口运行。测试涵盖五种 ZIP 格式转换、路径/链接/大小写拒绝、导出隐私与双哈希、更新基线、CurseForge API 契约及下载限制、数据包过滤/世界路径、外部资源批量启停及回滚、旧加载器元数据、跨平台词库、TOML 依赖、导出配置、应用撤销、批量更新与外部修改保护。HTTP fixture 中的 Key 是测试字符串，无真实权限；这些测试不代表生产 CurseForge 已联网成功。最近新增测试结果以主线程最终整合测试报告为准。

真实联网和文件链路证据：

1. `artifacts/evidence-complete/pack-live-2/pack-live-result.json`：真实缓存中 Fabric 1.20.1/Mod Menu 实例导出后重新导入，资源哈希一致，66 个库有效。新实例 `pack-roundtrip-08-b9f21f27` 可供独立启动检查。
2. `artifacts/evidence-complete/pack-live-3/pack-live-result.json`：再次导出/导入为 `pack-roundtrip-08-ee19135f`，仅修改这个测试副本的 config 并删除它的 Mod Menu，更新为 `pack-update-c5e40805afbe`，确认用户新增和删除得到保留。原 fabric-1.20.1 不改动。该 roundtrip 副本删模组是测试操作，启动验收宜用前述 b9f21f27。
3. 同一真实联网记录：Modrinth TreeMiner，项目 a7UP7ozo，版本 DFl6nWg8 / 5.0.0，19,397 bytes，SHA1 `a9e9a1a63c70f5cefc7bbf333c286a872e70896f`；在 `world-staging/saves/世界 数据包验收/datapacks` 下载校验并安装。该目录仅复制已有世界的 level.dat，未修改原世界，也没有进入该 staging 世界验证游戏行为。

本模块没有把 .app 真实按钮操作、游戏启动、渲染初始化或世界玩法混称为同一证据。主线程的最终 GUI/启动记录可另附；本页不预填尚未发生的成功。CurseForge 真实账号 Key、受限下载文件的合法手动取得、各种大型外部整合包和新数据包的世界行为仍需相应验收。
