# 按改动选择测试

先完成 [环境检查](开发快速开始.md)。统一入口从仓库根目录执行，实际调用现有脚本和控制台断言；每次 .NET 测试自动分配新的 artifacts/dev 子目录，结果保留供查看。

| 命令 | 执行内容 | 需要什么 | 不证明什么 |
|---|---|---|---|
| `python3 dev.py test quick` | 模块引用边界（含注入反例）、组件包夹具、核心基线校验夹具、开发文档本地链接 | Python、Git；无需 SDK/网络 | 未执行 C#、真实 Host、GUI 或游戏 |
| `python3 dev.py test core` | 构建并执行 Pcl.Tests 核心控制台套件 | SDK、Unix cc；首次 NuGet 还原需网络 | 不等于真人登录、全平台或世界保存验收 |
| `python3 dev.py test contract` | 构建真实 Host，执行最小客户端 contract 套件；握手、状态、取消、重连等 | SDK、Unix cc、本机进程/管道；可能请求官方元数据 | 不完成游戏安装、不使用真人账号，不保证完全离线 |

不指定 suite 时 test 默认 quick。命令会打印所执行的子命令，失败立即退出非零；不能用 `dotnet test` 的空成功替代这些控制台程序。

`python3 dev.py test sources` 构建并执行来源错误夹具及真实 Host 状态探针，是 [完整扩展示例](扩展示例-搜索来源状态.md) 的一键验收。使用合成密钥和独立目录，不需要真实 CurseForge 密钥，不证明线上授权可用。

## 改动对应的最低验证

| 改动 | 起点 | 进一步验证 |
|---|---|---|
| 文档和开发入口 | 链接/命令检查，quick | 改动的入口实际执行；入口回归见下方 |
| 项目引用、源码导出、组件结构 | quick | `.github/workflows/project-boundaries.yml` 的独立工作区验收 |
| 解析、兼容规则、安装与文件逻辑 | core | 对应功能套件及失败/取消行为 |
| Contract、Client、Host 会话 | core + contract | 消息兼容、事件及跨版本测试 |
| 账户登录状态、任务并发 | core | Pcl.ClientLogin.Tests、Pcl.ResourceConcurrency.Tests、Pcl.DesktopQueue.Tests |
| CurseForge 来源 | core | Pcl.CurseForge.Tests，真实 Host status 探针 |
| 系统凭据、独立日志 | core | Pcl.PlatformCredentials.Tests、Pcl.LogProtection.Tests；隔离系统服务或临时钥匙串 |
| 内容包或 Host 更新 | quick + contract | Pcl.ContentPack.Tests、Pcl.HostUpdates.Tests；签名、兼容与回退 |
| UI、原生窗口、游戏启动 | 相关规则/协议测试 | 测试 Desktop、目标系统实际交互及游戏行为 |

专项参数和隔离条件以 [Core CI](../.github/workflows/core-ci.yml) 和各测试 Program 为准。系统凭据测试不能直接拿个人默认钥匙串或桌面 Secret Service 做破坏性边界测试；CI 已提供隔离环境步骤。真实游戏和账号验收仍需显式准备，基础命令不会自动执行。

开发入口本身的错误传播和目录隔离回归：

```sh
python3 scripts/test-dev-entry.py
```

完整 UI 测试构建、环境变量、独立组件验收见 [开发指南](开发指南.md)。报告应列出命令、平台、通过/失败/未执行及原因；三平台自动化结果与真人账号、GUI、存档结果分别记录。
