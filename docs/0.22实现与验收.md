# PCL Mac 0.22 实现与验收

本版围绕 0.21 的同一份 121 个 Windows 设置控件补齐实际行为。原 40 个未完成项中，21 项直接绑定，14 项已部分实现，1 项改为固定隐私行为，4 项仍未完成。部分实现不算原版完全兼容。逐行状态见 `0.22-settings-binding-audit.json` / `0.22设置逐项核对.md`。

## 本次实际实现

- 游戏窗口：本 Java 进程中的 Cocoa agent 修改 NSWindow 标题、最大化，并将低优先级设置为 nice 10；默认/自定义/启动器尺寸联动，实例字段继承也一并加入。
- 五种启动器可见性：隐藏恢复、最小化、保持、游戏退出后关闭，以及关闭启动器后游戏独立运行；独立进程输出写入日志文件，避免父进程关闭输出管道导致游戏退出。
- 本地音乐文件夹、随机顺序、刷新重扫、游戏内播放策略、停止不重启；本地背景随机目录、平铺、9 方位填满、自动小图平铺、彩色叠加；标题图片加载/清空，动态配色与动画速度。
- 导航及版本/模组管理按钮细粒度隐藏，隐藏设置本身后仍可通过“恢复界面”或 Ctrl+Shift+H 恢复。
- 版本清单与 Modrinth API 的 HTTPS 来源顺序、超时和无效 JSON 回退；真实资源文件名格式及显示顺序；带哈希验证的跨目录复制开关、脱敏下载调试日志和可取消延迟。
- G1 调优；LWJGL Unsafe Agent 2.0 固定 SHA256 构件，只在 Java 25+ / LWJGL 3.4.0–3.4.1 启用，可禁用。26.3 实际使用 3.4.3，会跳过此 Agent。
- 从已安装客户端提取随机、Steve、Alex 纹理并持久化资源包。保留离线 UUID；未强行修改手臂模型，未宣称服务器皮肤同步。

## 证据与边界

本轮隔离测试在 `artifacts/verification-0.22`，由 0.21 测试目录写时复制；不使用或修改用户重要存档，不读取微软登录凭据。

- 228 项核心回归通过，含缓存复制开关实际 HTTP 请求差异、无效 JSON 回退、音乐真实 afplay 切歌/停止、资源改名后安装/更新/禁用/移除。
- Java 8/21/25 上的 Minecraft 1.12.2、1.21.1、26.3 完成图形初始化，窗口回执包含实际标题、尺寸、nice=10。
- 五种启动器可见性由真实桌面程序和 1.21.1 子进程检查；独立启动确认父进程关闭后游戏继续完成 GUI 纹理加载。
- LWJGL 3.4.1 原生内存读写在 Java 25 上分别开启和关闭 Agent 测试，启用日志明确记录 MemoryUtil 方法改写。
- 皮肤测试从真实本地客户端提取三类 PNG，重新读取账户索引并逐一比对生成包内 18 张纹理。
- 图形初始化、窗口属性与自动停止不是本轮“进入世界/保存/重进”验收；本次没有重新请用户完成世界内验证。测试主动停止产生的 137 不算自然退出成功。
- 发布包的最终 GUI 保存/重开/布局检查和截图见随附验收包及 review 页面；实际统计以 final-*.json 为准。

## 仍有缺口

- 原版玩家名抓取正版皮肤和刷新共 3 项，以及原版赞助流程 1 项仍未完成。
- 原版第三方 WPF XAML 主页、赞助身份/解锁、PCL 原版节点服务、签名更新/公告/识别码/土豆码仍没有完整兼容。
- 高/实时进程优先级不在 macOS 普通用户权限下模拟；动态彩色和启动字样浮层不是原版动画算法。
- 资源名称暂取发布名，中文项目译名尚未贯穿所有来源；散列反查及其他社区 API 尚未统一镜像策略。原文件名与资源管理校验、事务恢复保持有效。
- 动画速度控制本次动态颜色及启动浮层；调试开关提供实际脱敏下载日志，均不宣称覆盖原版全部内部动画/调试点。
- 应用为 Apple Silicon / macOS 14+ 自包含包，临时签名，未经 Apple 公证。
