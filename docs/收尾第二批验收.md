# 收尾第二批：更新忽略、图标、文件选择器与导出隐私

日期：2026-10-27。基于 0.40.1 后的本地源码构建；没有覆盖 GitHub 已发布的 0.40.1 包。本轮仅修改更新忽略页面的错误处理和列表刷新行为，其余新增内容是验收探针及记录。

## RES-017 忽略模组更新

发现并修复两处问题：未选择任何更新时原来仍显示成功；成功忽略一个版本后原来清空全部更新列表。现在未选择会提示“请选择要忽略的更新”，仅在 Host 持久化成功后移除所选条目，其余更新保留。

使用 Modrinth 官方 API 下载并校验 SHA-1 的 Fabric API 0.102.0+1.21.1 与 Mod Menu 11.0.1，置于隔离 Fabric 1.21.1 实例。真实 Avalonia 页面从实际目录取得两个更新，完成空选择拒绝、选择忽略、其他更新保留、关闭重开后再次查询。新启动的第二个 Host／UI 进程再次查询，仍只显示另一个模组更新。

忽略文件只记录 Fabric API 目标版本 ID，两份原 JAR 的 SHA-1 均未改变。没有下载或启动新版模组，不把本项称为模组兼容或游戏启动验收。该项限定到 Modrinth 资源更新；没有外推 CurseForge 密钥路径。

## INST-004 图标保存与恢复

用户通过真实 macOS 图标选择器选择合成 PNG。程序确认 Host 保存后的图标可渲染，关闭重开实例页面后图标字节一致，再执行“恢复默认图标”，确认 Host 已移除自定义图标且页面不再显示该图片。

用户确认已完成原生文件选择操作。这是一个 PNG 样本的真实选择／保存／页面重开／恢复默认验收，不代表每种 JPEG 编码、每个尺寸及图标跨进程重启全部重新测试。名称描述保存保留已有历史限定证据。

## UI-007 设置文件选择器

用户通过 macOS 保存对话框导出 JSON，再通过打开对话框选择同一个文件导入。导入前测试主动改变标题，排除“值本来相同”的假阳性；导入后核对 Host 状态，重开设置页面确认恢复的标题已显示。

结合上一批真实 Host 的重置、备份及无效 schema 拒绝记录，本轮补齐文件选择器链路。额外构造带媒体路径、主页路径、Java 路径、JVM／游戏参数、服务器地址和世界名称的导入文件，确认这些字段净化为空；随后导出的 JSON 仅保留可移植设置。没有执行导入文件中的命令。

## PACK-011 导出包含项与隐私

通过真实 Host 的 `workspace.packs.export` 及 Client 分块取回生成两个 mrpack，逐项检查 ZIP 实际内容：

- 已知账号、凭据、令牌、认证文件、服务器列表、锁文件、日志和隐藏文件排除；包含嵌套路径和大写文件名负例。
- 只选 config 时，不包含 resourcepacks；普通配置保持原内容。
- 默认不含存档和游戏选项，显式选择后才包含。
- 导出的内容未包含隔离宿主绝对路径。
- 指向实例外文件的配置符号链接被拒绝，未交付半成品文件。

**已验证的限制：** `config/custom-service.json` 内人为放置的 `apiKey` 合成标记仍会导出。当前规则按路径／文件名和选择范围排除，不能自动识别任意模组自定义配置里的秘密。此观察保留为限制，不算安全保护通过；界面已有分享前检查私密配置的提示。若要求“任意配置秘密也自动发现”，这是另一个需要设计和实现的能力，不能从当前验收推出。

## 结果与复现

脱敏结构化记录：[收尾第二批验收结果.json](收尾第二批验收结果.json)。原始本地输出在 `artifacts/closeout-second/`；不应把整个运行目录上传为验收附件。

新增入口：

- Desktop `--file-picker-acceptance --acceptance-files <fixture-folder> --acceptance-report <report>`：需要人工完成原生选择器；测试 PNG、导出 JSON 放在指定目录，导出名称为 `PCL-Mac-settings.json`。使用全新隔离 `--data-root`。
- Desktop `--update-ignore-acceptance --acceptance-report <report>`：需要预置 `update-acceptance` Fabric 实例及两份仍有更新的旧版公开模组；第二次同数据根加 `--updates-restart` 验证持久化。公开目录会变化，后续复现应记录当次版本而不是硬编码本次“最新”。
- `Pcl.Workspaces.Tests --export-privacy <fresh-data-root> <report>`：自动创建合成文件，经真实 Host 导出；测试环境必须允许本地 Host 的 Unix socket 通信。

Desktop 使用 `PCL_HOST_ASSEMBLY` 指定构建出的 Host DLL，`PCL_DOTNET` 指定本地 SDK。所有 GUI 探针的最终结论以 JSON 的 status 为准，不能仅看进程退出码。

编译通过，架构守卫零违规，保留原有 Desktop 3 个警告。新增更新探针首次编译误用 Contract 未提供的 Sha1 属性，改为同一条目的 Path 比较后编译通过；最终另从隔离文件检查 JAR 哈希。隐私探针首次因沙盒无法连接 Host 超时，在允许本地通信的执行环境复测通过。两者不是业务功能修复。

本轮没有读取真实钥匙串、执行微软登录、进入 Minecraft 世界或验证跨网联机；不将这些行为标为重新验收。四个矩阵项只在以上限定范围更新为已验收，复杂依赖、整合包兼容和任意配置内容的隐私限制仍保留。
