# Plain Craft Launcher Refactoring 0.36.1

这是第三方基于PCL独立二次创作的内部开发版本，并非PCL官方后续作品。PCL原作者为龙腾猫跃（LTCatt），[支持原作者](https://meloong.com/afd/a/LTCat)。项目继续保留并使用原始PCL-LICENCE.txt作为指南，不将其替换为CC BY-SA。

## 许可展示与限制

关于页首位显示原作者署名及其赞助链接，随后显示完整产品名、版本、独立第三方声明、源码入口和随包指南。Windows主题主色固定为蓝色，禁用动态变色和图片替代标题，不设置赞助解锁。

按所有者本轮决定，源码仍在私有仓库，故“公开源代码”尚未满足；关于页明确展示这一限制。0.36.1仅作内部开发基线，不声称已完全满足指南或可公开分发。原版指南链接的石墨分发许可本轮无法通过网页读取，因此也不把实施检查当作完整法律合规结论。

## 启动前劝导

对照固定上游源码的McLaunchPrecheck：原版按启动次数提示赞助和购买。本版在每次启动前显示原作者支持提示；尚未验证过正版的离线用户每次都显示正版购买提示，频率高于原版。中文流程允许阅读后继续离线启动；非中文流程在尚未验证正版时只允许官方试玩或取消。正版验证成功仅保存匿名的“曾验证”标志，不保存账号或令牌。点击赞助/购买链接不会直接启动游戏，赞助完全自愿且不解锁功能。

窗口只展示Host返回的规则；game.launch.v2在执行边界验证确认数据，未确认不能创建进程。关闭窗口或取消提示不会提交启动操作。旧receipt无确认字段时保持原指纹解释，但新启动必须经过提示。导出启动脚本按上游保存脚本例外不显示启动劝导。

## 版本和隐私基线

0.36.1使用新的单提交Git基线和新私有仓库，不继承旧Git对象、标签或旧发布包。旧版本验收产物不纳入新源码包；保留需要继续开发的架构与功能说明，历史测试记录不等于本版实测。

默认构建的微软OAuth client ID为空。开发者如需验证官方服务，仍须使用自己获准的应用标识和微软账号。钥匙串、游戏实例与存档不随代码或包交付，本轮也不删除它们。
