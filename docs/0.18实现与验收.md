# PCL Mac 0.18 实现与验收

日期：2026-10-24（Australia/Sydney）。Apple Silicon / macOS 14+ 开发版；不表示全部 PCL2 功能已完成。

## 新功能与修复

- 实例自定义分组：按实例保存，支持组合搜索、加载器、收藏/隐藏筛选；规范化 Unicode，限制 60 字符并拒绝控制字符。未分组与“全部分组”使用独立值，用户同名分组显示前缀以避免混淆。复制与备份保留分组。
- 实例 CLI 复制、备份和恢复复用原桌面服务。恢复创建独立 ID，按清单校验文件，重新检查游戏依赖，不覆盖原实例。该流程不要求第二个账号、密钥或登录。
- 官方 Quick Play 单人存档入口：在实例启动设置中逐字段覆盖，输入当前实例 saves 下的世界目录名；检查官方元数据、存档存在性及符号链接，禁止路径越界以及与多人目标冲突。旧版本不支持时明确拒绝。导入/恢复设置清空自动进入目标。
- Forge 直达保护：本机 Forge 52.1.20 在 Quick Play 进入世界时出现资源初始化错误。因此 0.18 禁止 Forge 单人 Quick Play，要求使用正常主菜单；附加参数同样不能绕入。没有修改 Forge 或模组 JAR。
- 退出状态不再仅依赖退出码：日志出现已识别的世界进入失败时，即使进程退出 0，仍提示查看世界/模组诊断。新增 Xaero serverData 与 Forge LootModifierManager 特征；只提供排查建议，不自动移除用户模组或世界。
- 修正使用说明中“微软审核未完成”的旧描述。内置应用已获批，普通用户使用已有正版微软账户即可登录。

## 本轮已完成

1. 210 项回归通过；编译 0 警告、0 错误。新增用例覆盖分组持久化/筛选/复制/备份、Quick Play 元数据与路径限制、Forge 保护和干净退出中的世界错误诊断。
2. 隔离目录的实际界面控件验收通过：分组保存、筛选、窗口重开、清除，以及 Quick Play 字段保存。解压后的 0.18 自包含应用再次通过同样的控件测试；截图已检查中文与布局。
3. 使用真实光影实例生成备份并恢复到新副本，23 个存档文件逐字节相同，原始世界未改动。
4. 恢复的 Fabric 1.21.1 世界经官方 Quick Play 进入、正常保存退出，再由独立游戏进程打开同一副本。第二次启动前的全部存档哈希与第一次退出后完全相同；两次均观察到服务器启动/停止、存档更新和进程退出码 0，日志无 ERROR/FATAL。用户明确确认画面、标记和位置正常。

## 失败与待验证项目

- 1.12.2 原版：用户反馈正常，但该次日志没有单人服务器启动，指定存档目录没有 level.dat；记录为待核对，不据此标为保存重进通过。
- Fabric 1.20.1：本轮手动会话只有标题初始化与正常退出，未形成世界存档证据。
- Forge 1.21.1 Quick Play：有小地图时 serverData 为 null，随后玩家被断开；仅在测试副本可逆禁用小地图后，Forge 自身仍因 LootModifierManager 尚未加载而崩溃。证据不能归咎于小地图独有问题，也不证明所有 Forge 版本都有相同问题。小地图已在测试副本恢复；失败世界保留于该副本的 world-tests-failed。
- Forge 普通菜单对照：用户两次反馈正常，但本轮没有单人服务器启动/停止，存档文件无变化，游戏由 20 分钟超时停止，暂记待核对。NeoForge 1.21.1、Quilt 1.21.1 和原版 26.3 的独立测试副本已准备，尚未完成本轮世界验收。不得把 0.17 的标题界面测试升级为本轮世界测试结果。
- 真人双微软账号切换仍因无第二个账户待验收；CurseForge API 等需要密钥的范围保持原矩阵状态。

`artifacts/verification-0.18/` 内的 `final-regression2/test-results.json`、`group-ui-final/evidence/instance-groups.json`、`world-backup-restore.json`、`worlds/fabric1211-roundtrip.json`、`packaged-ui/evidence/instance-groups.json`、每个会话的 before/after 文件哈希、进程日志与结果 JSON。用户反馈单独保存；工具记录与反馈不一致的会话保留为 needs_review。

自有源码继续保留功能/实现注释和逐层换行，第三方源码不做此类重排。新 QuickPlayWorld 配置字段不保证旧版本解析，回退前应保留设置与世界备份；本轮功能矩阵仍有未完成项。
