# 0.42.1 客户端自更新（本地阶段）

应用版本 **0.42.1**，客户端 build / 更新序号 **423**，Host 序号保持 **42101**。基于最新核心 `81016b476e8811ecbfbd3f969d143b646ac5282d` 和前一阶段的数据包适配；本次没有修改 Host/Core 业务实现。仅在本地提交，未推送或发布 GitHub 附件。

## 实现行为

客户端启动后，若安装包预置 `client-update-policy.json`，自动检查并下载更新；“关于”页面可手动检查或选择“安装客户端更新并重启”。游戏运行时拒绝重启。未配置策略时保持关闭，不使用示例地址作为默认更新源。

更新器是独立、自包含的 `Pcl.ClientUpdater`。启动前复制到应用目录之外，等待原客户端退出并取得所有客户端的运行锁，再替换目录。超时不会强杀原客户端。更新完整 `.app` 时使用 macOS 原子目录交换，目标路径始终存在；纯客户端目录也整体交换，继续使用外部 Host，不重新拼装业务 DLL。

信任来自原安装包内固定的 RSA 公钥。签名清单使用 RSA-PSS/SHA-256，包含版本、递增序号、平台、频道、包类型、HTTPS 地址、大小、SHA-256 和到期时间。下载禁止重定向，限制字节数与超时；拒绝旧序号、错误频道/平台、过期或篡改清单、错误公钥、包哈希不符、ZIP 路径穿越、链接及重复路径。替换前再次验证；Mac 应用还验证 bundle 身份、版本和 `codesign --verify --deep --strict`。此处代码签名为本地 ad-hoc，发布信任由固定 RSA 公钥提供，不等于 Developer ID 公证。

重启沿用原数据目录与参数。新客户端完成 Host 连接和窗口初始化后，写入带随机 nonce、进程身份及序号的就绪确认；更新器再观察三秒。启动失败或 60 秒未就绪，恢复旧目录并重启旧客户端。失败序号保留在高水位中，避免反复安装。更新中断后，下一次启动使用已保存并验证哈希的旧更新器完成恢复；不能确认目录哈希时拒绝覆盖。

完整应用包内的 Host 必须通过协议/能力预检且序号不下降，已配置的 Host/内容更新策略必须一致。纯客户端包不携带 Host。客户端与 Host 的序号独立：这次只增加客户端序号，不虚增 Host 序号。

## 构建与签名

`build-release.sh` 和 `build-components.sh` 均生成 `client-release.json` 与 `updater/`。客户端和更新器只引用 Client/Contract，不依赖 Core。现阶段自更新支持本机 macOS ARM64；其他平台不宣称具有此实现。

构建时可通过 `PCL_CLIENT_UPDATE_POLICY=/absolute/path/policy.json` 注入策略，字段为：

```json
{
  "FeedUrl": "https://your-update-host/client/osx-arm64.json",
  "PublicKeyPem": "-----BEGIN PUBLIC KEY-----\n...\n-----END PUBLIC KEY-----\n",
  "Channel": "preview"
}
```

正式策略和私钥由发布方管理；仓库不内置正式密钥或更新源。不同包类型使用独立清单地址。候选包必须保留安装端的策略，更新序号大于已安装和已尝试序号。旧 build 422 没有此更新器，需要先安装包含本功能的版本。

```sh
python3 scripts/sign-client-update.py \
  --archive /absolute/path/client.zip --kind macos-app \
  --url https://your-update-host/client.zip --channel preview \
  --key /secure/path/private.pem --dotnet /absolute/path/dotnet \
  --tool tools/Pcl.UpdatePack/bin/Release/net10.0/Pcl.UpdatePack.dll \
  --output /absolute/path/new-client-feed.json
```

纯客户端 ZIP 改为 `--kind client-directory`。签名工具校验候选包中公钥与签名私钥配套，不会把私钥放进包。完整应用先签署并打包，再签更新清单。

## 本机验收与限制

复现入口（原生 Apple Silicon macOS，.NET 10 SDK，Xcode Command Line Tools）：

```sh
DOTNET=/absolute/path/dotnet bash scripts/test-client-self-update.sh /absolute/path/fresh-output
```

脚本创建一次性测试密钥和隔离数据目录，构建真实应用及自包含更新器，生成签名候选包，执行真实进程退出/替换/重启和回退。生产启动不启用测试模式；测试模式要求显式参数和隔离目录标记。

具体结果见[本轮验收记录](0.42.1-客户端自更新验收.json)。HTTP 下载使用 HttpClient 替身传输；不等于正式 HTTPS/CDN 联调。未验证 Windows/Linux、真人账户、实际游戏会话、公证和断电持久化。中断恢复测试覆盖原子交换前后持久化日志状态，不模拟突然断电。就绪确认保证启动链路，不能覆盖启动之后所有功能错误。

成功后保留旧应用和事务证据；目前没有自动清理历史下载、暂存目录和旧备份。正式渠道配置、密钥托管与缓存清理策略仍属于发布运维事项。
