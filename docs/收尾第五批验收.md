# 收尾第五批验收：批量实际测试与启动故障修复

日期：2026-10-27。基于 0.40.1 后本地源码，在 Apple Silicon Mac 上执行。完成 14 项限定范围验收，修复两个真实启动故障；并未完成全部剩余项目，也没有发布新安装包。可携带的脱敏证据见[结果 JSON](收尾第五批验收结果.json)，更新后的[剩余清单](剩余清单.md)保留未完成边界。

## 两个产品修复

### Apple Silicon 上的旧版 LWJGL2 首线程

原版 1.12.2 在完成 atlas 初始化后发生原生 SIGSEGV，栈经过 `glCopyTexSubImage2D`、AppleMetalOpenGLRenderer 和 Objective-C 消息调用。旧规则对 LWJGL2 排除了 `-XstartOnFirstThread`。在同一隔离副本中只加入该参数，真实菜单观察 30 秒通过；随后修正产品规则，让 macOS aarch64 的 LWJGL2 同样使用首线程，保留非 ARM64 的原有判断和参数去重。

修复后清空自定义 JVM 参数，用默认设置启动同一 1.12.2，菜单持续观察 60 秒通过；LiteLoader 1.12.2 菜单观察 15 秒通过。代码在 `LegacyLaunchAdapter.RequiresFirstThread` 和 `LaunchService.CreatePlan`，既有兼容测试增加 ARM64 分支。该证据不等于进入世界或长期稳定性验收，也不外推所有 LWJGL2 程序。

诊断时参考了[上游同类原生崩溃讨论](https://github.com/maxmanolov/vertex/issues/144)；本项目结论基于本机同副本的失败、单参数对照和默认设置复测，并非只凭该讨论判断。

### 非默认实例的依赖预检误判

当前 Host 启动既有 OptiFabric 1.20.1 副本时，预检错误地将 Minecraft 内置组件版本设为共享 service 的默认值 1.21.1，拒绝了原本兼容 1.20.1 的 OptiFabric。修复 `LaunchService.PrepareAsync`，从所选实例 profile 读取并验证 `gameVersion`；只有旧 profile 缺失该字段时才回退 service 版本。

新增回归测试分别验证：1.20.1 实例的兼容依赖能够通过至后续客户端完整性检查；改为不兼容版本后仍被 Fabric 依赖检查拒绝。测试故意使用损坏客户端作为停止边界，不绕过完整性检查，也不运行伪造游戏。

修复后真实 Host 成功启动固定组合 Minecraft 1.20.1 / Fabric 0.16.14 / OptiFabric 1.14.3 / OptiFine I6，ARM64 Java 17，菜单观察 30 秒通过。使用的是已有组件的隔离副本，本轮没有重装该组合、进入世界或人工确认光影，因此 VER-014 保留待验收。

## 测试自身的修正

首次全套为 226/230。四项失败来自过时断言：完整性失败现在包裹为 IOException（内层 InvalidDataException）；Fabric 的 `^0.6.1` 接受 0.7.0 而非 npm 语义；官方试玩身份应允许；使用现代 depends 的 Java 约束样本遗漏 schemaVersion 1。逐项对照当前契约修正后为 230/230，新增实例版本回归后为 231/231。独立调用真实 Fabric Loader 解析器也确认 `^0.6.1` 对 0.7.0 为 true、对 1.0.0 为 false。

UI 探针最初在 Show 再次触发 Opened 时重复执行，已加入一次性保护；独立进程观察脚本最初漏匹配 `detached-game-*.log`，已修正。这两项是测试工具问题，不计为产品修复。旧版渲染日志匹配补充后增加持续观察，才暴露了真实的首线程崩溃。

最终 Desktop/Host 与测试项目编译通过，架构守卫 0 违规。完整 Desktop 构建保留原有 3 个警告；最后一次增量构建报告 0 警告，不能据此宣称消除了那 3 个既有警告。没有改动账户、钥匙串、皮肤逻辑；相关自动化测试通过，但本轮没有真人微软重新登录或皮肤游戏内验收。最终进程核对未发现本批隔离目录所属的存活测试进程。

## 历史证据与剩余项目

对原 34 项定向验收逐项登记原证据路径、可用性及 SHA-256。发现 30 个缺失引用（含重复，21 个不同路径），集中于部分旧 architecture/verification 产物。保留缺失事实，不依据不存在的报告关闭项目。历史 Forge、NeoForge、26.3 世界保存及 0.37–0.39 报告单列为“核对历史”，不是本批重新游戏验收。

当前 131 项中：**68 项已覆盖限定范围、35 项实现缺口、20 项定向验收、8 项外部条件验收**。标签口径另为 67 已验收、15 已实现待验收、42 部分实现、2 未实现、4 外部条件阻塞、1 平台适配；分类口径不同，不能简单相加比较。实现缺口未因验收改标签而减少；未新增矩阵子进度。
