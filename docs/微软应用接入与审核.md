## 历史验证（0.12）

第一次真人授权：微软网页确认登录成功；Xbox 用户身份交换返回 400。检查发现 .NET PostAsJsonAsync 默认将 Xbox 要求的 PascalCase 字段转成 camelCase；改为保留字段名的 JSON 序列化，并增加请求体断言。

第二次真人授权：微软 OAuth、Xbox 用户令牌和 XSTS 交换通过；Minecraft `authentication/login_with_xbox` 返回 403。原始令牌未写入文件或测试报告，本轮未请求记住登录。证据：`artifacts/microsoft-live-0.12-retry/evidence/last-error.json`。403 本身不等于已取得审核拒绝结论；当前新应用尚无 API 审批结果。官方审核申请已于本轮提交成功，页面显示 Thank you for contacting Mojang Studios.，尚无批准结果。

自动测试与界面证据位于 `artifacts/microsoft-integration-preflight/`。协议夹具不替代实际正版登录、Keychain 重启刷新或游戏启动验收。

## 已获用户确认的功能调整

用户确认按官方申请要求调整：下载和安装免登录；启动游戏必须先完成微软身份、Java 权益及玩家档案校验。正式流程不再提供未验证离线启动、匿名试玩入口或离线启动脚本导出。历史离线/外置账户资料保留供管理，不作为新版游戏启动凭据。

游戏启动服务在创建进程前检查认证服务签发的内存验证记录、身份、令牌和有效期。仅把 UserType 写成 msa、从磁盘反序列化账户资料、修改已验证会话或传入旧试玩会话，均不能通过。离线 UUID 与旧数据读取工具保留；旧版本包的测试证据不代表 0.12 仍支持未验证启动。

Justification（已提交）：

PCL_Mac is an independent, pre-release desktop launcher for macOS, initially targeting Apple Silicon. It manages Java runtimes, game installations, mod loaders, mods and modpacks. We request Java Edition game service API access to authenticate users, verify their Java Edition entitlement, retrieve their player profile, and launch their legitimately owned game. The application uses Microsoft device-code authorization with XboxLive.signin and offline_access as a public client, followed by Xbox Live and XSTS authentication. It does not collect account passwords or use a client secret. Launching requires a valid Microsoft-authenticated session with a verified Java entitlement and profile. Unauthenticated full-game launch and offline launch-script export have been disabled in this application build. Users can download and prepare installations before signing in. Access tokens stay in process memory; refresh tokens are stored in the macOS Keychain only when the user chooses to remember sign-in. This is an independent application, not an official Mojang or Microsoft product.

Additional information（真实边界）：

The new application registration supports personal Microsoft accounts and public client flows. A live test completed Microsoft OAuth, Xbox user authentication and XSTS, but the Minecraft login_with_xbox endpoint returned HTTP 403. We are requesting review of this new AppID before making Microsoft sign-in generally available. Automated authentication contract and launch-authorization tests are available; full end-to-end game launch with this AppID is pending API access. Earlier development builds supported unauthenticated launch; the current application build removes those paths.
