# PCL Mac 0.29：搜索与设置 Host 迁移

日期：2026-10-25。按当前 v1.3 规范（保留 v1.2 原则）继续阶段三。

## 已实现

- UnifiedSearchWindow、CurseForgeWindow、SettingsHelpWindow、CacheNetworkWindow 只依赖 Contract / Client；编译后符号守卫覆盖四页，包括生成的异步状态机。
- Host 持有多源分页/去重/失败来源重试、兼容版本查询、依赖求解与下载、百科本地 JAR 导入、CF 手动文件哈希校验、整合包下载预览及可选项安装。文件来源与校验信息保存在 Host 私有选择记录，界面只传选择句柄。
- 设置快照、冲突检测、校验、全局启动/网络/启动前程序保存、便携导入导出、主页读取/示例/预设，以及缓存预览/回收/恢复和有界网络探测由 Host 执行。设置导入仍保留原白名单与备份规则，不导入或导出可信启动前程序。
- 修复跨序列化器将 1 与 1.0 误判为配置冲突；修复背景文件夹模式错误读取空单图路径；防止异步设置导航覆盖后续页面。
- 新页面关闭时请求取消并等待操作结束；沿用现有 Host 任务受理、receipt、会话重连、登录和游戏独立进程机制。

## 明确限制

- 未提供真实 CurseForge API key，不声称已实际验证带密钥的官方搜索/依赖接口。手动文件路径使用固定元数据替身，其结果与公开 Modrinth 实测分开标记。
- 搜索会话最多 16 个、有效 30 分钟、每会话 100 页；同一 Host 重连保留分页，重启后需重搜。密钥只存在 Host 内存，30 分钟过期；不会写入任务收据。
- Desktop 仍引用 Core：MainWindow、默认资源浏览器的查询展示，以及账户/皮肤/联机等遗留页面仍需继续迁移。尚未删除兼容授权。
- 新写入在未知提交中断后仍拒绝盲目重放，需检查结果再发起新任务；不声称任意崩溃点均可自动续做。
- 不将编译或渲染器初始化当作玩家进入世界、保存与重进验收。
- 交付为 Apple Silicon 自包含应用，本地 ad-hoc 签名，未公证。
