# 0.42.1 五类分包收尾

本轮范围按用户确认固定为五类：客户端包、Host 核心包、数据与内容包、外部工具与运行环境、开发与验证工具。验收重点是包之间的实际连接性。Core 内部适配器、Legacy、上游库不再继续细拆；多仓库、跨语言 SDK 和公开 SDK 发布不是本次完成条件。

版本保持 0.42.1 / 客户端 build 425 / Host 42102 / 数据 42102，最新核心基线 81016b4。本轮仅补收尾验收和说明，不改变运行代码或更新序号。

包间长期维护和接入约定见[五类包连接规范](五类包连接规范.md)。

## 五类职责与连接

| 类别 | 内容和归属 | 连接与验收 |
|---|---|---|
| 客户端包 | Desktop、CLI、匹配的 Client/Contract SDK、客户端自更新模块及运行助手 | 经版本化协议访问 Host；不构造核心实现。已验收客户端和独立 SDK 客户端均连接成功，自更新后可重连 |
| Host 核心包 | Host、Application、Domain、Ports、Core、Legacy、必要上游实现、配套 Contract 与自包含 .NET 运行时 | 独立进程承担业务、凭据、数据根与工具进程所有权；签名更新后 SDK 可连接新 Host |
| 数据与内容包 | 百科与项目映射签名数据；内置索引作为安全回退 | Host 验签、兼容检查并加载；安装后下次 Host 启动生效，客户端通过协议查询状态和搜索结果 |
| 外部工具与运行环境 | 现有游戏 Java、EasyTier 及固定游戏兼容运行资产 | 按工具版本和平台管理，由 Host 检查/调用；Java 通过真实进程检测，EasyTier 通过两节点数据传输与退出清理验证 |
| 开发与验证工具 | 构建、签名、导出、诊断和测试程序 | 生成、校验前四类交付；不成为用户运行前置。生成的客户端更新助手属于客户端运行资产，不因源码位于 tools 就算开发工具 |

SDK 是客户端接入资产，Contract 在两端配套携带，不增加第六种用户更新包。外部工具按各自版本管理，不要求合成一个通用压缩包。首次安装 `.app` 可组合客户端和 Host；这是安装器组合，不恢复源码依赖。

## 可复现的收尾检查

- `test-independent-clients.sh`：独立导出/编译核心与客户端，运行真实 Host 契约与 CLI 连接。
- `test-client-self-update.sh`：真实 Mac 客户端签名、退出替换、重启及回退。
- `build-unified-release.sh`：临时测试密钥下构建数据、客户端、Host、完整安装器，校验签名清单与实际交付字节。
- `test-package-connectivity.sh`：补充数据自动更新/缓存、真实 Java 与真实 EasyTier 连接检查。参数为独立 Host、Java 21 可执行文件、已校验 EasyTier 2.6.4 Mac ARM64 ZIP 和全新结果目录的绝对路径；DOTNET 指向 .NET 10。

本轮使用已验证的真实工具缓存，不重复下载，不修改个人运行目录。EasyTier 输入先按核心固定 SHA-256 验证，再复制到隔离测试目录；真实节点仅运行本地回环通信。

## 验收范围

结果见[五类分包收尾验收](0.42.1-五类分包收尾验收.json)，此前客户端拆分和自更新证据见[项目拆分验收](0.42.1-项目拆分验收.json)。记录区分本轮重新运行与沿用的相同运行代码证据。

完成判定只覆盖本地 macOS ARM64 五类包的维护边界和已列出的连接路径。正式 HTTPS/CDN、生产签名和公证、远端 CI、跨平台运行、互联网 NAT 联机、完整 Minecraft 世界游玩及真实微软登录不计入本次范围，也不宣称已验证。同一数据根仍是单写入会话，不允许多个客户端同时各自启动可写 Host。

- 真实 EasyTier 两节点连接与退出清理：10 项通过。

结论：按上述五类包及本地 Mac 连接性范围，本次收尾完成；没有待修复的已知分包接线问题。生产发布与其他平台验收仍按明确范围单独处理。
