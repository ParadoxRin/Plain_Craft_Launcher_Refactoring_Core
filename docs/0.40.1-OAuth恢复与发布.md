# 0.40.1 · OAuth恢复与发布

日期：2026-10-27。目标为macOS 14+ / Apple Silicon，上传原有新私有仓库。

- 经应用所有者授权，恢复此前注册的PCL_Mac公开OAuth client ID。它标识应用，不代表用户账号；不包含client secret、密码、租户ID或用户令牌。
- 正式包可直接发起微软设备码授权，用户登录自己的微软账号。现有账号刷新沿用其原始应用ID，IAccountSecrets及钥匙串行为保持。
- 一并交付0.40的Core/Application/Domain职责整理、统一窗口生命周期、百宝箱移除和矩阵核对。矩阵为41项历史限定验收、36项待验收、47项部分实现、2项未实现、4项外部阻塞、1项平台适配，共131项；不是本版全量验收声明。
- 历史版本保留其原有空配置；不改写Git历史，不恢复旧私人资料。

## 验证范围

本版检查编译、内置公开应用配置、HTTP替身授权字段、最终Host对微软真实设备码端点的申请与取消、真实窗口生命周期及Host工作区流程。设备码申请不会自动完成用户登录；不能据此声称新版正版权益、刷新、钥匙串或游戏世界已经实测。

最终结果以发布附件验证报告为准。此前测试保留各自版本与范围，不自动升级为0.40.1重新验收。

## 隐私与发布

应用及ZIP继续扫描私人路径、令牌、私钥和运行时资料。Git历史扫描仅通过显式参数允许本次授权的公开client ID，其他非空应用配置仍报告；不放宽凭据检查。扫描不是对未知敏感模式的绝对保证。

自包含应用使用ad-hoc签名，未进行Developer ID公证。libpclwindow的install name保持`@rpath/libpclwindow.dylib`。
