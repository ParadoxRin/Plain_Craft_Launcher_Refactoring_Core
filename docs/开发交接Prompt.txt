你接手的是 Plain Craft Launcher Refactoring 0.36.1 私有开发基线。

先阅读 README.md、docs/0.36.1-内部基线与验收.md、docs/architecture/PCL-Mac架构规范.md、docs/架构与设计取舍.md、docs/功能实现导览.md 和 docs/0.36-剩余清单.md。

获取与历史：克隆 ParadoxRin/Plain-Craft-Launcher-Refactoring 或解压本版带Git包。运行 git status、git log --all --oneline、git fsck --full；基线为一个提交与v0.36.1标签。禁止从旧PCL_Mac、旧bundle或旧交接包合并历史，不能重新带入已清理的个人信息。后续提交可以正常追加。旧版本技术文档是参考，不等于本版实测，旧产物路径可能不再存在。

架构：Desktop为暂用Avalonia Shell，只调用Contract/Client；独立Host拥有执行、账户与进程生命周期。Application编排，Domain为纯规则且不引用Ports，Core/Adapters提供现有实现。Mac目标UI为SwiftUI，Windows/Linux分别使用原生库，尚未完成。不要为换UI重写已验证的安装链。继续复用InstallOperations -> VersionInstaller；凭据沿用IAccountSecrets，不进入Shell、receipt或普通RPC。

当前能力：免登录下载，多版本与加载器安装；微软和离线账户；皮肤获取/保存/刷新；Modrinth与多源资源；模组依赖和多种整合包；实例复制/备份；Iris事务撤销、共享依赖保护；operationId、取消、幂等、快照、事件、会话恢复及部分安全续做。每项支持范围以矩阵和剩余清单为准，不宣布PCL全部等价。

剩余工作：35项实现缺口仍在，包括完整复杂依赖语义、更多整合包兼容、Oculus卸载、部分自动修复/更新、3D皮肤、外置账户和原生UI。部分验收需要第二微软账户、API密钥或其他平台。优先无需额外账户的真实实现，不做矩阵子进度，不靠改状态或写说明关闭缺口。

0.36.1：产品显示名为Plain Craft Launcher Refactoring。关于页首位是龙腾猫跃署名和其官方赞助链接，明确第三方作品。每次启动显示原作者支持提示，未有正版验证记录的离线账户显示购买提示，非中文未验证流程仅试玩/取消。game.launch.v2在执行器检查确认，并将其纳入幂等指纹；先game.guidance再展示再确认。不要给旧测试增加生产绕过开关。赞助不解锁功能。Windows蓝色限制需保留。源码目前私有，尚未满足公开源码要求，不能对外宣称全部许可要求已满足。

保留行为：数据根、bundle和钥匙串标识不因改名而变；登录、皮肤、离线身份、窗口退出及独立游戏行为保留。不得读取/上传个人令牌、密码、钥匙串、存档或完整游戏进程命令行。默认OAuth client ID为空：验证微软功能需要你自己的获准应用ID以及自己的微软账号，仅有账号不能替代应用ID。

构建：Apple Silicon macOS14+，Xcode CLI、Python3、curl，global.json固定.NET10.0.402。执行bash scripts/build-handoff.sh，输出artifacts/Plain Craft Launcher Refactoring 0.36.1.app。支持DOTNET指定SDK。当前ad-hoc签名、未公证；未配置云端CI。

测试：见docs/开发与验证.md。--license0361运行策略、执行边界和幂等/恢复定向测试；--license0361-smoke运行真实Avalonia/Host关于页和启动提示交互。另有--iris036、--txn035等套件；使用全新隔离目录。HTTP替身、编译、标题渲染、进世界与人工确认分别报告，不混称平台验收。旧启动探针未提供Guidance时会拒绝，这是契约变化，不应关闭生产检查来迁就测试。
