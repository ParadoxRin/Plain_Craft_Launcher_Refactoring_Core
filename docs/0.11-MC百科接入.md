# PCL Mac 0.11：MC 百科接入

入口：侧栏“MC 百科”，或“多源搜索 → 来源 → MC 百科”。

## 已实现

- 使用 PCLCS 随附的 26,283 条 MC 百科索引，按中文名、平台 slug、数字 ID、class/download 链接搜索；空搜索浏览，20 条分页。索引本地读取，离线可用。
- 合并同一百科 ID 的平台映射，但不按同名猜测项目身份。每个条目保留百科资料与站内下载页面。
- 选择条目后，按索引中的明确 Modrinth slug 查询官方 API，核对项目类型、slug、文件 project_id、Minecraft 版本及加载器，再提供版本安装。继续使用原有前置解析、哈希校验和事务安装。
- 没有 MR 映射、映射已过期、请求失败或没有兼容版本时明确提示；不会把百科列表出现等同于兼容。部分映射失败不丢弃其他可用项目。
- 百科站内下载在浏览器完成；“导入已下载 JAR”调用现有导入器，检查压缩包路径、模组元数据、加载器和已实现的依赖约束。缺少前置时拒绝导入并保留原文件。

## 实现边界

这是“百科索引 → 对应发布项目安装 / 百科网页下载 → JAR 导入”的接入。百科内置索引不是本站实时 modlist 抓取；本版不新增百科私有 API，也不自动提交验证码。无 MR 对应项时不会借用他人的 CF API Key 或猜测下载地址。百科和 Modrinth 同项目可能分别出现，尚未跨来源全局去重。

MC 百科公开下载页具有验证码及线路选择流程。本机直接连接 www.mcmod.cn 和 search.mcmod.cn 出现连接重置，内置浏览器也失败；应用实际探测结果保存为 `mcmod-network.json`。因此站内验证码下载未完成实测，网页结果不能当作桌面直连成功。

内置索引来自原 PCL 固定基线，不会自动更新；新收录模组需用“百科检索网页”。平台映射可能过期，安装前仍核验发布项目和文件。

## 证据

- `artifacts/evidence-0.11/regression/test-results.json`：158 项，含中文/ID/链接/分页、离线无请求、类型/身份/版本/加载器重验、局部失败、取消及仅 CF 条目不猜测 MR。
- `artifacts/mcmod-candidate-3-0.11/evidence/mcmod-result.json`：候选实测；首轮远端版本请求失败与第二轮缺少缓存的测试准备失败记录分别保存在 candidate、candidate-2 目录。
- `artifacts/mcmod-final-0.11/evidence/mcmod-result.json`：最终 ZIP 解压运行的实测，以回执状态为准。
- `artifacts/release-verification-0.11.json`：包哈希、源码独立重建及最终证据索引。

实测路径是通过界面搜索“锂”、百科链接定位、查询并安装对应 Modrinth 版本，再下载官方 FerriteCore JAR 调用同一个导入方法。下载页按钮仅验证打开的目标 URL；文件选择器未自动操作，未声称文件来自百科服务器。Minecraft 1.21.1/Fabric 0.20.1 使用独立复制的 Minecraft/Java 缓存，实际联网下载模组，GUI 启动后检查图形/图集初始化与 45 秒存活，测试主动结束；不是世界/存档验收。
