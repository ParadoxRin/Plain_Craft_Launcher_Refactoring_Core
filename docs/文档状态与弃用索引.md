## 文件名标签

- `【已弃用】`：已被替代的指导文档或状态快照。保留内容以便追溯，不作为当前实现或配置要求。
- 历次实现／验收／隐私审计报告：保留原文件名和当时的验收范围。历史报告仍是证据，不能仅因版本较早就判为弃用，也不能代表本版重新验收。
- 许可证、第三方声明及原始验收 JSON 不因年代而弃用。功能矩阵仅更新文档引用，不调整状态或数量。

弃用标签整理仅涉及文档与关联路径；后续 main 的代码维护另见上述验收报告，均不覆盖已发布的 v0.41.0 标签、安装包或校验文件。
