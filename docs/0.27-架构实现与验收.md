# PCL Mac 0.27：组件与文件下载执行迁入 Host

本批按现行架构规范（v1.3，延续 v1.2 的依赖与生命周期约束）进行增量迁移。保留 Avalonia、原安装算法、账户存储及钥匙串作用域；不表示全部旧页面已迁移，也不表示完整 PCL2 功能对等。0.26 及更早包保留。

## 实际调用链与职责

| 用例 | Shell / Client | Application / Host | 原流程 |
|---|---|---|---|
| 调整加载器 | ComponentManagerWindow → IComponentPageService → LauncherSession | page.begin → PageOperationService → IPageExecutor | PageExecutionAdapter → InstanceComponentService |
| 下载文件与更新说明 | ArtifactDownloadWindow → IArtifactPageService | 同一持久化页面任务队列 | ArtifactDownloadService，保留来源和校验规则 |
| 历史、取消、续做 | PageTasksWindow → IPageTaskService | page.get / page.cancel / page.begin，分页状态资源 | 原操作历史保留，续做建立新 operationId |
| 保存已完成文件 | 用户选择本机目标，Client 写临时文件 | 只开放成功下载对应的私有文件句柄 | 每块最多 256 KiB，完整 SHA-256 复核后原子发布 |

三个窗口只使用 Contract 接口/DTO，IL、签名及生成嵌套类型的守卫禁止它们引用 Core 实现。Client 仍仅引用 Contract；Application 只经 Ports 调执行器，Domain 不引用 Ports。Desktop 项目仍引用 Core：实例、模组、整合包、设置等旧页面尚在过渡期，不能删除整个项目引用。

默认生产入口使用独立 Host。显式 `--in-process` 兼容模式保留，由组合根选择 Core/Adapters 中的本地适配器；旧页面安装/下载执行代码已从 Desktop 的适配器移出。工厂的 remote 参数不再有默认值，调用点必须明确选择模式。

## 受理、恢复与退出

- `PageCommand` 限定已登记用例；不接受客户端指定任意 URL、Java 参数或 Host 路径。版本目录、预览与文件校验都在受理并落盘 operationId 之后执行。
- 幂等作用域为当前数据目录、命令类型和幂等键。相同输入返回原操作，改变输入拒绝；队列与 worker 由应用服务持有，禁止无主后台任务。
- 页面操作使用既有独占执行通道和兼容写入授权。旧页面持有写入权时 Host 拒绝受理；页面任务执行时旧写页面禁用，三个 Host 页面保留查询/取消能力。安装、启动、账户变更与页面任务互斥。
- 状态快照落盘后发事件，复用先订阅再取快照、序号去重、有界队列及重连策略。断线不等于取消；显式取消才发送取消请求，取消等待者也不冒充已停止任务。
- Host 正常退出取消/等待页面任务后再释放执行器和存储。崩溃后非终态变成 interrupted；显式续做生成新的 operationId，同时沿用原执行身份，防止重复发布实例或混用文件。
- 存储失败后拒绝新写入，当前等待者收到内存中的 `interrupted / STORE_UNAVAILABLE`；不宣称失败时终态已经持久化。
- 私有组件计划及文件选择持久化在 `page-execution-v1`，公开状态在 `page-operations-v1`。两者使用独立 OS 锁文件，仍受整个数据目录 Host 锁保护。

## 组件安全边界

复用原指纹复核、备份、安装新加载器、复制存档与配置、Mac Java/natives 检查和短提交流程，不改写源实例。执行身份固定暂存、新副本和回执的位置；中断未发布的暂存目录保留为历史，再重新准备及校验。已存在目标且 committed 回执可确认时，再校验实例身份、依赖库与复制文件指纹后返回同一结果；提交窗口无法确认时拒绝重复发布并保留现场，返回 `COMPONENT_COMMIT_REVIEW_REQUIRED`。

成功预览绑定原执行身份；新操作不能再次消费同一计划。源实例变化必须重新预览。恢复不承诺跳过所有已下载或已复制步骤，以安全重新执行为准。

## 文件边界

Host 将文件下载到操作私有目录，保留原官方 SHA-1、PCL2 已知校验值及仅作者来源等不同验证状态。客户端只能使用成功任务的资源句柄读取，不能提交任意 Host 路径。文件资源不受原 16 MiB JSON 资源限制；本批限制单文件 2 GiB、每连接 16 个资源句柄、句柄有效期 5 分钟。断线/过期后重开句柄，从偏移继续读取，最终验证完整 SHA-256。

目标已存在时拒绝覆盖；取消或错误删除本次临时导出文件。后台下载成功后，即使用户取消保存，仍可在“后台任务”中重新保存，无需再次下载。

页面快照结果上限 512 KiB；历史最多 4096 项、非终态最多 16 项。大目录和长期历史整理仍需后续分页/保留策略扩展；本批不宣称无限历史或任意大小目录。文件下载目前报告准备/完成阶段，未新增逐字节的下载进度。

## 限制与后续迁移

- 新 UI 在旧 UI 崩溃且遗留兼容授权时仍可能遇到 `LEGACY_RECOVERY_REQUIRED`；不按 PID 或超时夺权。Host 崩溃后不能恢复已失去托管身份的游戏。
- 本批游戏测试验证进程启动和图形/材质初始化，不等价于人工进入世界、保存、重进或从菜单正常退出。主动测试停止单独记录。
- Forge、NeoForge、Quilt、OptiFine、LiteLoader 沿用既有组件算法，本批新增 Host 组件崩溃恢复的真实测试主要覆盖 Fabric 与原版；不把其他加载器历史测试算成本批重测。
- 账户登录/外观仍沿用现有实现，未迁移其查询协议。未新增客户端密钥，不向 Desktop 发送令牌。
- 后续继续迁移实例维护、资源/整合包执行及设置持久化，再删除 Desktop 的 Core 引用；SwiftUI 和非 Mac 平台未在本批实现。

包为 Apple Silicon 自包含应用，本机 ad hoc 签名，未公证。
