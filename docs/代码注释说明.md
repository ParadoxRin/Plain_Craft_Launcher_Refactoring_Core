# 自有源码注释与维护

范围为 `src/` 下的 Pcl.Core、Pcl.Desktop、Pcl.Cli 与 Pcl.Legacy：类、记录、方法、局部函数和有大括号的执行逻辑块。关键分支说明来自实际条件与语句；字段、表达式中的每个操作符和对象初始化器不逐项添加解释。第三方 `vendor/`、生成目录 `bin/obj/`、历史归档与用户运行数据保持原样。测试夹具不作为产品源码注释覆盖率统计。

注释有两层：

1. 人工编写的模块用途、关键算法与事务说明，描述功能、输入输出、实现过程和边界。集中映射保存在 `scripts/code-comment-domains.json`、`scripts/code-comment-overrides.json`；新覆盖模块亦有手写 XML 文档注释。
2. 标记 `[实现]` 的结构说明由 Roslyn 语法树生成，列出方法或代码块的实际条件、数据准备及操作顺序。此类说明用于阅读导航，不表示逐行人工审计或成功运行结论。

工具 `scripts/CodeComments` 只改注释和空白，再逐 token 验证前后原始类型及文本一致，并重新解析核对，防止注释吞掉代码或改动字符串。原有来源、许可和人工注释保留。VB 与 AXAML 使用人工注释并通过同一解决方案编译检查；不计入 C# token 审计。

修改功能后更新人工映射，再运行：

```sh
.tooling/dotnet/dotnet run --project scripts/CodeComments/CodeComments.csproj -c Release -- "$PWD"
```

随后正常构建与运行测试。新的审计输出在 `artifacts/comment-current/comment-token-audit.json`（历史 0.15 报告保留在原目录）。仅注释阶段的 token 等价不代表本版相对旧版没有功能改变；新增覆盖与事务修复由专门测试验收。

## 嵌套排版

自有源码使用四空格缩进。对象与集合初始化器、嵌套调用、条件表达式和 XAML 子控件逐层换行；简单常量参数可以保留同行。字符串中的内容和注释中的示例文本保持原样。VB 的单行条件语句展开为 `If / End If`。

`CodeComments` 已复用 `CodeFormat/NestedLayout.cs`，更新注释后也会保留逐层展开的排版。单独调整排版时运行：

```sh
.tooling/dotnet/dotnet run --project scripts/CodeFormat -- "$PWD"
python3 scripts/format-xaml.py
```

两条命令均支持 `--check`，只检查、不写回。C# 工具覆盖 `src/`、`tests/` 和 `scripts/` 的自有 C# 文件，跳过 `bin/obj`；先验证所有文件的语法 token、注释、指令与重复格式化结果，再写回。XAML 工具验证元素、属性、文本、注释及顺序等价，保留混合文本和 `xml:space="preserve"` 区域。新的审计位于 `artifacts/formatting-current/`，历史交付包不被覆盖。

本版审计：103 个 C# 文件，1,078 个类型/方法/局部函数声明及 1,882 个执行块均有对应说明（方法体由方法说明覆盖）。未注释声明和执行块均为 0；103 个文件的注释阶段 token 校验全部通过。VB 和 AXAML 另有人工说明。
