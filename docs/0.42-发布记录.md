# 0.42.0 Preview：统一模组浏览与 Host 更新

本版交付 macOS 14+ / Apple Silicon 的 Avalonia 参考客户端与独立 Host，仍合装在同一 `.app` 中；另提供精确标签的源码 ZIP、SHA-256 校验和及脱敏验收结果。应用版本 0.42.0，build 420，Host 构建序号 42000。沿用现有 bundle 标识、数据根和系统凭据作用域。

## 本版纳入

- 统一模组浏览：全部来源/游戏版本/加载器筛选、保守的跨站身份合并、按目标实例和来源选版本，下载安装复用 Host 依赖与事务。
- 可配置的 Host 签名更新：兼容检查、签名清单与逐文件校验、空闲/下次启动切换、启动失败与未确认候选回退。更新 SDK 仍只依赖 Contract。
- 独立最小客户端、会话/恢复契约、Mac/Windows/Linux 系统凭据适配及自 v0.41.0 后合入的维护修复。
- 按客户端、Host、数据与内容、外部环境、开发验证工具整理仓库入口和职责说明。

默认不启用官方更新频道。发布者仍须提供可信公钥、签名包与 feed；此 Release 下载页不等于已经建立签名自动更新源。没有 UI 自身替换、跨数据格式自动迁移、词库独立更新或通用动态插件加载。
