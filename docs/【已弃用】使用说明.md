# PCL Mac 0.19 使用说明

面向 macOS 14+、Apple Silicon 的第三方本地移植开发版。应用自带 .NET 运行时；Java、Minecraft 和加载器在安装时按需下载。原作者为龙腾猫跃，本项目不是官方 Mac 发行版。当前仍是开发版，尚不能称为 PCL2 全部功能已验收。

## 下载、安装与启动

打开 `PCL Mac 0.19.app`，点击“下载版本”，搜索 Minecraft 版本并选择加载器。默认自动匹配稳定 Fabric，无可用版本时安装原版；也可选择原版、Fabric、Forge、NeoForge、Quilt、OptiFine、LiteLoader。Quilt 是扩展能力。版本列表并非全版本兼容保证；具体实测组合见《旧版加载器与Java16适配》和《多版本与Mac兼容性》。

安装无需登录。下载会校验缓存和完整性，Java 按游戏主版本与 ARM64 架构匹配。在“任务与诊断”可暂停/继续文件下载、重试文件、取消当前主操作；中断的版本安装在“安装记录”选择继续。继续会校验缓存并重新执行必要的安装步骤，整合包中断仍应重新导入原文件。

0.19 恢复 PCL2 风格的离线登录：在首页选择“离线登录”，输入 1–16 字符玩家名，可直接点“启动游戏”，也可点“使用此名称”保存到历史账户。相同名称沿用固定 UUID；可以切换和移除离线账户。离线身份不等于微软正版验证，不能用于要求在线认证的服务器。已安装且依赖齐全的实例不需要微软账号或 OAuth 配置即可离线启动；首次下载缺失文件仍需联网。

选择“微软账号”时仍验证 Java 版权益与角色，注销或令牌失效不会自动切换成离线身份。源码默认不含应用 client ID；接手开发者需按[开发配置](微软登录开发配置.md)提供自己的应用标识后构建，用户再登录自己的微软账号。记住登录时刷新令牌进入 macOS 钥匙串，离线账户不读写钥匙串。外置账户当前只保留管理功能。

“皮肤 / 披风”管理微软账户的皮肤与已有披风，也可为离线账户选择本地 PNG。离线皮肤通过本地资源包替换默认材质，保留账户 UUID；它不会让其他玩家看到在线认证皮肤。外置账户的皮肤功能由服务器声明的能力决定。

## 实例和资源管理

“实例管理”支持导入游戏目录、名称/描述/图标、自定义分组与组合筛选、收藏、首页隐藏、复制、备份/恢复、回收站、补全修复（0.12 已取消离线启动脚本导出）。全局/实例设置包括 Java、内存、窗口、JVM 参数和自动加入服务器。组件修改通过独立副本迁移，保留源实例；存在模组时需要审阅兼容性和副本禁用选择。

0.13 新备份包含逐文件校验清单；“实例管理 → 校验备份”无需联网，可在恢复前检查文件损坏。旧备份会提示没有逐文件哈希。恢复会创建新实例并保留原实例，但仍需联网补全共享依赖，不能视为完全离线迁移包。

“多源搜索”按项目 ID 跨页合并，上一页读取本次搜索的缓存。修改关键词、分类或在线来源会清空旧查询；失败来源可用“重试本页”恢复。项目数会因去重而变化，同名不同项目不会误合并。

Modrinth 页面包含模组、光影、资源包、数据包、整合包，按实例版本与加载器筛选。中文别名与百科关联来自固定的 PCLCS 数据。CurseForge 使用用户自己的 API Key；发布者不允许自动下载时进入官方页下载，再用本地文件匹配校验。钥匙只保留在该窗口内存。

“本地资源”扫描实例现有文件，进行批量启停、更新与依赖检查。安装/变更先检查依赖与冲突；无法可靠解析的约束会报出，不将不确定条件视为兼容。数据包需选定存档，安装后在游戏中确认数据包加载。光影与资源包可以应用/撤销，更新保留备份。

“Mac 配置 → 1.21.1 光影”创建独立实例，固定 Java 21、Fabric、Iris/Sodium 和 Complementary MEDIUM 配置。Iris 官方没有 Apple Silicon 驱动支持保证；之前的指定组合已由用户确认世界画面正常，不能推广为其他光影或所有 Mac 支持。

## 整合包、联机和设置

“整合包管理”导入 mrpack、CurseForge、HMCL、MultiMC、MCBBS 与普通 ZIP。普通包需指定游戏/加载器。外部包中的启动命令与脚本不会自动执行。导出可选择存档和配置，默认排除账户等隐私。整包更新以新实例合并，按初次安装哈希保留用户改动；缺少基线的旧包不猜测覆盖。

“联机”使用 EasyTier ARM64 无 TUN 模式：房主先在 Minecraft 开放局域网，填入游戏显示的端口和双方可连接的节点；朋友输入此 Mac 版邀请码，在游戏中连接提示的本机端口。它使用独立的 PCLMAC1 邀请码，不承诺与 Windows PCL 私有节点协议互通。已完成本机双进程端口转发实测，双人世界游玩另需验收。

“设置与帮助”提供深浅色/系统主题、颜色、背景、音乐、游戏时隐藏、导航恢复、自定义 JSON 主页、设置导入导出与帮助搜索。JSON主页支持文字、网页、复制、消息、导航、启动、刷新和加入房间；操作需要用户点击，不执行远程 XAML 或脚本。启动前本地程序由用户显式配置，仅保存在启动器目录，不随整合包/设置导入。等待失败或超时会阻止本次游戏启动。

“任务与诊断”可导入日志、识别常见 Java/依赖/图形/网络问题、导出脱敏诊断 ZIP。游戏正常退出、异常退出和用户主动结束分别显示；结束游戏前应保存存档。

## 文件、验证和边界

默认数据目录为 `~/Library/Application Support/PCL-MacPort`。1.21.1 原版兼容旧路径 `minecraft`；其他实例位于 `instances/`，共享经过校验的库与 assets。运行包和源码包均不含 Minecraft 客户端、Java、用户账号或测试存档。

查看《PCL2完整功能矩阵》了解逐项状态；《0.8实现与验收》区分自动测试、真实下载、GUI、图形初始化和人工世界验收。微软真实授权、外置真实账户、CurseForge 真实密钥、双人游戏等缺少外部条件的项目不会被模拟测试替代。Intel Mac、全部历史版本及所有模组/光影组合未得到保证。

本地包采用 ad-hoc 签名，未进行 Developer ID 公证。保留原有 0.7 应用与原始 ZIP。未配置线上发布/签名更新源，当前不自动更新。支持原作者：https://meloong.com/afd/a/LTCat 。

网络页可启用大文件分段下载（默认关闭），不支持Range时回退；测速与临时缓存管理支持小样本检查和可恢复的临时文件清理。首次游戏默认中文，已有语言保持不变。Mac配置另提供固定1.20.1 OptiFabric组合，需手动提供合法来源组件或自有CurseForge Key。

## 0.18 新增操作

- 在“实例管理”的分组栏填写名称并保存即可创建/分配分组，留空移出分组。左侧分组、加载器、收藏/隐藏和搜索条件可组合。复制与备份保留分组。
- 在实例“启动设置”勾选“快速进入世界”的自定义开关，填写当前实例 `saves` 下的存档文件夹名称；该世界必须已存在，游戏元数据必须支持官方 Quick Play。不能同时设置自动加入服务器。当前 Forge 直达路径已在本机触发资源初始化异常，因此本版要求 Forge 从游戏主菜单进入世界。
- CLI 新增 `instance-copy --profile <实例文件夹> --name <副本名称>`、`instance-backup --profile <实例文件夹> --file <新ZIP路径>`、`instance-restore --file <备份ZIP>`，复用桌面服务，不需要登录。恢复生成新实例，不覆盖原实例；共享资源/Java 仍需校验或下载。
- 恢复/导入设置会清空 Quick Play 目标，避免意外打开世界。新增 QuickPlayWorld 设置不能保证旧版解析；需要回退时请保留数据备份，并使用与设置匹配的应用版本。
