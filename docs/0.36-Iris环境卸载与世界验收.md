# PCL Mac 0.36 · Iris 环境卸载与世界验收

## 实际实现

- Iris 安装前记录原本不存在的组件，安装完成后记录 SHA-256；既有组件保留，不暗中升级共享文件。旧版或手动安装没有可信安装前记录时不自动追认归属。
- 资源正常安装入口登记用途；环境卸载检查其他用途、实际 Fabric JAR 的必需依赖、嵌套模块、别名和禁用组件。依赖版本谓词参与判断，优先复用保留的提供者或独立 API，避免把 Iris 内嵌模块误认成唯一依赖。
- 界面显示将移除、将保留和冲突集合。取消不执行卸载；确认后 Host 重新检查文件、清单及依赖指纹。游戏运行时由 Host 原有互斥拒绝写入。
- 组件和前后清单备份刷盘后写入提交意图；只删除逐个验证的文件，以原子替换更新清单和归属。崩溃后先验证备份、保留组件、用途和清单，再安全续做；发现新增依赖、文件改动或损坏备份时停止并阻止游戏启动。
- 每次最多128个组件。配置、光影包、存档、Fabric 加载器和手动文件均保留。下载失败且尚未引入文件时恢复可启动状态；部分写入则保留现场，等待原安装重试。已完成卸载可幂等重试；卸载后重新安装不会把旧环境用途误判为新共享用途。
- Shell 只显示 Contract 数据并提交 Host 操作；未新增 Desktop 对 Core 的引用。登录、钥匙串与游戏进程所有权沿用原边界。

## 本轮修复

实际 Sodium Extra 测试发现：独立 Fabric API 与 Iris 的嵌套模块提供相同依赖时，原算法把全部提供者都保留，导致 Iris 无法卸载。现在结合版本谓词优先保留非 Iris 提供者；真实共享实例和定向用例均通过。另补齐卸载后重装的旧用途处理、下载未写入即失败时的启动恢复、符号链接循环拒绝与依赖覆盖配置拒绝。

## 明确保留的限制

- 仅支持有可信归属的 Fabric/Iris 环境；Oculus、Forge/NeoForge 后端的环境卸载仍待实现。
- Fabric 官方支持 `config/fabric_loader_dependencies.json` 覆盖依赖；本版发现该文件会拒绝卸载及中断续做，不能仅按 JAR 猜测删除集合。参考：[Fabric Dependency Overrides](https://docs.fabricmc.net/players/troubleshooting/dependency-overrides)。外部自定义模组目录/特殊类路径不在本轮自动卸载支持范围。
- 文件改名、禁用、内容或清单归属改变时保留并报告冲突；不会覆盖用户修改。失败安装遗留的外部用途记录可能保守地多保留文件，不自动清理这些记录来扩大删除范围。
- 原有较新生物群系/uniform兼容警告仍保留；本机指定组合验收不等于任意光影、全部Mac或长期稳定性保证。
- 验证了真实进程退出边界，没有模拟硬件断电或文件系统损坏。提交后的取消不撤销已开始的有限提交，重启按持久化回执续做。
- 本轮一个微软账户已实测，没有第二账户切换或新增密钥平台的验收。未新增矩阵子进度，132行分类不变，35个宽口径实现缺口继续保留。

Apple Silicon 自包含包，ad-hoc签名，未做 Developer ID 公证。使用 `打开PCL-Mac-0.36.command` 沿用原数据目录和钥匙串命名空间，不复制凭据。
