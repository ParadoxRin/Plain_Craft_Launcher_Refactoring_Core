# PCL Mac 0.9：免账号功能补齐

继续在 0.8 主工程上开发。本版补齐矩阵 JAVA-009 和 PACK-009，并修复实际安装时发现的 Fabric 元数据瞬时超时。仍是开发版，132 项功能没有全部完成；0.8 的多版本、用户世界反馈与本版测试分开保存。

## 本版变化

- 实例启动设置可逐字段选择“自定义”，未选字段跟随全局设置。支持内存、窗口、全屏、Java、JVM/游戏参数、服务器；显式空值与关闭全屏不会被当作继承。修改全局值若导致实例内存范围冲突，会提示实例目录并保留原设置。
- 复制实例和备份恢复保留字段继承关系。导入备份仍清除外部 Java/启动参数/服务器覆盖，不执行包内命令。
- Modrinth 与 CurseForge 清单可逐文件选择可选项，支持全选/全不选；必需项自动安装，服务端专用文件不安装到客户端。CurseForge 未提供 API Key 时继续支持用户手动匹配本地 JAR，不声称验证了远端身份。
- 首页整合包下载、导入及整合包工作台均接入选择流程；选择写入安装回执。相同原包的不同选项默认生成不同实例，保留原实例与用户文件；预览后包内容变化会要求重新检查。
- Fabric/Quilt 列表、配置和 Maven 校验值读取复用有限重试：最多三次，每次 45 秒，遵循有界 Retry-After；用户取消不重试。此项针对首次真实安装测试暴露的超时，不代表网络永久故障一定可恢复。

Modrinth 行为依据[官方 mrpack 规范](https://support.modrinth.com/en/articles/8802351-modrinth-modpack-format-mrpack)中客户端环境、可选文件对话框及哈希字段。PCL 对应逐文件提示见 `Modules/Minecraft/ModModpack.vb:274-280,417-425`；Mac 使用集中勾选窗口。

## 设置升级

0.9 首次写入启动/实例设置时将 `launch-settings.json` 从 schema 1 升至 2，先在同一数据目录的 `settings-backups/launch-schema1-*.json` 留下原文件逐字节备份；只读查看不会迁移。原来的完整实例覆盖仍保持原行为，需要用户取消相应“自定义”才能开始按字段继承。

使用同一数据目录前请退出 0.8，避免两个版本同时写入。0.8 不认识 schema 2；回退时应关闭应用、保留新设置副本，再用该目录的 schema 1 备份恢复 `launch-settings.json`。回退会丢失备份之后的启动/实例设置变更，不会还原游戏存档。本版旧实例备份仍可导入，0.9 新备份需要 0.9 或更新版本恢复。
