# PCL Mac 0.8：实现、验收与剩余工作

本轮在现有 `pcl-mac-port` 上继续开发，不另建简化核心。交付目标为 Apple Silicon、macOS 14+ 的本地自包含应用；仅当前 Mac 实测，未实测最低系统版本或 Intel Mac。版本名称保留 0.8 开发版：仍有缺项，不能称为完成 PCL2 2.99.0.0 全部功能。

## 当前产品

一个 Avalonia 桌面入口调用 `Pcl.Core`；CLI 调用相同业务服务。继续保留 SwiftUI 0.5 工程作原生交互参考，它没有替代主产品，也没有自动继承 0.8 能力。默认数据目录、账户、实例、资源清单和任务状态统一，不要求用户操作隐藏的演示页面。

新增内容包括实例复制、备份、回收站、图标与启动设置；多代加载器、Java 16、LWJGL 2 和固定 OptiFabric 组合；整合包多格式导入/导出/更新；Forge/NeoForge TOML 依赖、资源批量更新事务；下载任务、可选分段下载、网络检查和临时缓存回收；外置认证、皮肤/披风、诊断、EasyTier、本地个性化和安全主页。

这些名称不代表任意版本/资源/包都兼容。132 项功能矩阵保留所有未实现、部分实现和外部阻塞项；2953 条源码符号/页面记录是盘点入口，不是已经逐行验收的证明。完整行为链路追踪仍有待核实细项。Quilt 是额外扩展，不冒充此 PCL 基线已经确认的自动安装能力。

## 核心与 MeloongCore 复用

| 层 | 当前职责和边界 |
|---|---|
| MeloongCore.Shared | 保留通用配置、原子文件操作、校验、路径、日志、进度等。Shared 保持 netstandard2.0；Unix 路径/链接、日志默认位置、跨平台 ECDSA 有适配 |
| PCLCS | 复用 Java 与资源模型、中文别名/百科数据；移除 WPF 依赖，适配 Java 路径/架构和跨平台嵌入资源名 |
| Pcl.Legacy | 从 VB 规则实现抽出明确的 OS/arch/features 判断 |
| Pcl.Core | 独立实现账户、安装计划、Java、下载、实例、资源、整合包、启动监督和诊断，无 Avalonia/WPF 引用 |
| Pcl.Desktop / Pcl.Cli | 一套核心的两个入口；GUI 提供主要用户操作，CLI 用于复现和测试，并非所有 GUI 操作都有 CLI 子命令 |

MeloongCore 不包含完整启动器核心。Windows 注册表、MsDelta、WPF 窗口接口没有转换成可在 Mac 上调用的功能；实例删除使用本应用可恢复回收目录，非强行调用 Windows 回收站。完整新旧来源哈希与差异见 `source-provenance-0.8.json`、`upstream-changes-0.8.patch`，早期来源记录保留。

## 数据迁移和失败恢复

0.7 默认数据布局与账户文件继续读取。新增网络字段缺失时使用“分段关闭/4线程”，不会使旧六字段配置失效；此问题已专门回归。首次游戏中文只在 options.txt 没有 lang 时写入，不替换已有语言。

实例改加载器先建副本，核对源文件指纹后提交；失败清理本次暂存目录，不覆盖原实例和世界。备份/恢复、回收站、资源更新和临时缓存移动会重检路径及链接。共享 assets/libraries/Java 不做未经引用分析的清理。版本安装恢复复用已校验文件并重新执行必要步骤，非任意安装器指令级续跑；整合包中断重新选择原包。

设置导出不包含账户、令牌、Java路径或执行参数；导入不会设置启动前命令。远程主页只允许有限 JSON 操作，点击时才执行导航/复制/启动等行为，禁止远程XAML或脚本自动运行。诊断只导出脱敏副本，不修改原日志。

## 尚未完成和外部条件

- 统一通行证专属登录未实现；微软和外置认证协议/Keychain有实现及模拟测试，但无真实账号端到端验收。缺合法 OAuth client ID 的情况已经记录，不重复索取。
- CurseForge 接口、手动受限资源流程已实现，缺自有 Key 的真实端到端验收。来源不允许自动分发时不绕过限制。
- 完整自动更新器、受信更新源、Developer ID 与 Apple 公证未完成；没有公开发布授权，本轮只本地交付。
- 原私有公告/节点/邀请码互通、百宝箱删节能力仍待核实。EasyTier跨网及双人世界未验收。
- 全局设置目前为整组实例覆盖；任意第三方实例继承链、复杂自定义patch/jarmod整合包、逐文件可选项UI、完整多源混合检索、全部依赖语言语义仍有缺口。
- Forge+OptiFine及任意历史组合没有通用保证；OptiFabric只开放固定实测组合。光影沿用指定组合的历史世界反馈，不推广至所有Apple GPU或全部光影。
- 断电一致性、实际磁盘耗尽、完整辅助功能、最低系统/Intel测试尚未完成；HTTP夹具和文件事务测试不是这些场景的替代证据。

## 构建与复现

在工程根目录使用 Apple Silicon Mac、Python3、Xcode Command Line Tools；首次运行 `python3 scripts/bootstrap-dotnet.py` 安装固定官方SDK（核验官方SHA512）。再执行：

```sh
./.tooling/dotnet/dotnet restore PCL-MacPort.sln --locked-mode
./.tooling/dotnet/dotnet build PCL-MacPort.sln -c Release --no-restore --disable-build-servers
./.tooling/dotnet/dotnet tests/Pcl.Tests/bin/Release/net10.0/Pcl.Tests.dll artifacts/retest
python3 scripts/merge-feature-status.py
python3 scripts/build-feature-matrix.py
bash scripts/build-macos.sh
python3 scripts/package-source.py
```

测试输出目录应每次选择新路径。真实游戏回归脚本 `scripts/verify-multi-version.py` 会下载并打开游戏，只在它创建的测试实例中观察启动；游戏/Java不包含在交付ZIP。源码包采用目录白名单，排除 artifacts、runtime、SDK、编译产品及凭据。应用 ad-hoc 签名，只证明本地包完整性，未公证。

重新生成完整矩阵需另备用户提供的固定PCL参考树；源码包已经附有生成好的矩阵，构建应用不依赖这些外部参考文件。元数据读取已补有限网络重试、Retry-After和45秒每次请求上限；解析失败/取消不会覆盖已有缓存。首次1.18.2清单超时的失败日志保留。

最终多版本复测已形成10个成功组合：1.16.5、1.18.2、1.20.1、1.21.1、26.3与26.4-snapshot-5原版；1.20.1/26.3 Fabric、1.20.1 Forge、1.20.4 NeoForge。按每份回执记录Java/图形/图集及30–35秒观察；均非世界内操作证明。汇总见 `artifacts/evidence-0.8/final-runtime-summary.json`。1.18.2首次官方清单超时仍保留，修复后复测通过。
