# PCL Mac 0.21 · 实用设置与辅助窗口

0.20 的设置占位已换为连接真实服务的表单。保存前验证、写盘后反馈成功；全局设置由没有覆盖该字段的实例继承。旧版 0.20 应用、压缩包及用户原目录保留。

## 本轮实现

- 启动：自定义版本信息、隐藏/最小化、全屏、宽高、自动/手动内存、Java 选择检查、JVM/游戏参数、GC 选择、服务器与 Quick Play、本地启动前程序/参数/等待超时。
- GC：Java 17 以下选择 ZGC 时回退 G1；分代 ZGC 在 21–22 增加 ZGenerational，23+ 不再传入该标志。自动内存取运行时可用上限一半并限制为 512–8192 MiB；手动内存不改变。
- 个性化：窗口透明度、静态配色、自定义颜色、背景文件/缩放/透明度/模糊、本地音乐/音量/自动播放/游戏跟随、标题文本、主页文件/HTTPS/教学文件/启动页呈现、导航隐藏与恢复。
- 下载：并发文件数、限速、镜像主机与顺序、代理、大文件分段数；通过 DownloadTasks.Configure 更新运行服务，代理重开应用后生效。
- 设置导入/导出、皮肤、联机、任务、缓存及诊断接入已有真实功能。导出不含账户令牌、命令和媒体文件。
- 新增 WorkspaceWindow，共用返回标题栏、白色工作区和左侧分类；业务控件保留原事件、取消和关闭逻辑。14 个辅助窗口实际打开检查，并非所有窗口的每项业务操作均重新验收。
- 修复快速编辑后立即保存的时序问题、根 TabControl 未左对齐、旧实例设置页遗漏新增字段、长标题裁切和配色预设/文本不同步。

## 原版逐项差异

详见《【已弃用】0.21设置逐项核对.md》和同名 JSON 审计。121 个原版控件中：35 直接绑定、22 部分绑定、4 现有功能入口、9 替代入口；40 项未完成、5 项外部服务未接入，另有 6 项固定策略或平台差异。这个计数以原版控件为单位，同一颜色/皮肤选项会单列，不能当作新增功能数。

尚未完成：原版皮肤预设/正版玩家名抓取、部分窗口策略、标题栏图片、随机音乐播放列表、动态彩色、全部背景锚点/平铺、Windows XAML 主页与第三方预设、细粒度隐藏、社区资源命名/管理样式、后台更新通知、原版专用调试选项。没有提供能点击却无效果的开关。

Windows 工作集清理、显卡注册表和 Java Launch Wrapper 不用于本机；TLS 证书继续验证。原版节点、签名更新、赞助解锁等服务没有被伪造。此版仍不是 PCL2 全部功能完成版，也不是像素一致移植。

## 验证与证据边界

- 核心回归 219/219 通过，覆盖新字段继承、非法值拒绝、GC 版本边界、真实启动参数和外观导入/导出。
- 最终 ZIP 解压后的实际窗口测试 68 项通过：设置与辅助窗口 32 项、独立进程恢复 9 项、联网搜索及旧导航 27 项。覆盖背景加载/缩放/模糊、真实教学文件按钮、主页呈现、导航隐藏、下载服务实时选项和 14 个辅助窗口。
- Minecraft 1.21.1 / Java 21：真实启动计划含 `-Xmx1536M`、G1GC、960×600 和测试 JVM 属性；图形/材质初始化后正常退出 0。
- Minecraft 26.3 / Java 25：真实启动使用 UseZGC、不传 ZGenerational；35 秒观察到图形和材质初始化，由测试结束进程（137）。这是主动停止，不计为正常退出或存档验收。
- 本轮没有重新测试微软登录、人工世界保存/重进、联机对端或可听音乐质量。
- 具体回执位于 `artifacts/release-verification-0.21.json` 与 `artifacts/verification-0.21/`，最终包独立解压后再运行界面验收。

GC 依据：[Oracle JDK 21 发布说明](https://www.oracle.com/java/technologies/javase/21-relnote-issues.html)、[JDK 24 迁移说明](https://docs.oracle.com/en/java/javase/25/migrate/significant-changes-jdk-24.html)。不把参数兼容性解释为性能提升保证。
