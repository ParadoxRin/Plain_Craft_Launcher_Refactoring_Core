# PCL Mac 0.32：Desktop 脱离 Core

本版优先完成架构规范 v1.2 的 Desktop 依赖清理。生产 Desktop 与 Client 只引用 Contract；Host 持有原有安装、账户、皮肤、资源、联机和进程服务。不存在兼容写入授权或同进程业务桥接。

## 实现及用例追踪

| 用例 | 规则和执行位置 | Shell 职责 | 独立证据 |
|---|---|---|---|
| 主窗口实例、账户和外观恢复 | Host DesktopSnapshot、原实例注册表和账户服务 | 缓存契约 DTO、绘制和选择 | ShellBoundary / BrowserAccount |
| 安装、修复、加载器和启动 | 既有安装/启动操作服务及工作区 | 提交、取消、显示事件 | MainLink / RemoteDesktop |
| 下载暂停、继续、重试及网络保存 | Host 原 DownloadTasks、DownloadService 和设置服务 | 按钮及表单 | ShellBoundary 真下载及 UI |
| 日志分析与诊断包导出 | Host DiagnosticsService、受控 blob 导出 | 展示/保存对话框 | ShellBoundary |
| 拖入资源、通知和窗口尺寸保存 | Host 工作区命令 | 拖入确认、提示及尺寸采集 | ShellBoundary |
| 账户和皮肤 | Host 原 AccountManager、IAccountSecrets 和皮肤服务 | 公开快照及图片渲染 | BrowserAccount / Microsoft |
| 关闭、重连和独立游戏 | 单一 RemoteLifetime / LauncherSession、Host 游戏策略 | 关闭界面任务、请求 Host 关闭 | Sessions / Detached |

主题绘制、背景图、主页受限标记渲染及界面音乐属于 Shell，使用 Contract 配置。业务验证和内容准备仍在 Host。历史命名空间 Pcl.Core.Contracts 的物理程序集是 Pcl.Contract，不能按字符串误判为 Core 引用。

Bootstrap 只组装 Client、会话及单一退出所有者，不构造安装器、账户存储或凭据适配器。历史同进程探针迁至 tests/LegacyDesktopProbes/0.31，不参与生产构建；内部 --in-process 参数明确报错。Host 构建依赖标为 ReferenceOutputAssembly=false，打包在独立 host/ 子目录，不向 Desktop 提供编译或运行时引用。

## 本轮发现并修复

1. 诊断 ZIP 已生成但新命令不在受控导出许可中：补充明确的导出方法，重测真实 ZIP 读取和脱敏。
2. 日志列表未加载时预选索引 0，首条诊断不显示：改为权威列表到达后选中；实际日志页和关窗重开通过。
3. 界面后台查询与安装/启动/认证受理竞态：Client 受理共享页面排队入口，保留 Host 的写入保护，未使用盲目重试。真实下载占用期间安装请求等待，前序终态后只受理一次；安装关窗取消及重开续做通过。
4. 异步版本图标增加选择修订号，旧结果不能覆盖新选择；下载暂停事件补充断线异常处理；后台重连由会话持有并刷新公开快照。

首次失败及超时记录保留。托管探针此前仍将“没有旧写入授权”误作“连接不可用”，已改为核对连接、禁用的游戏操作按钮和无授权字段；安装探针还改为检查本次新收据，不能借用历史成功记录。源文件嵌套格式按现有格式器展开，未修改第三方源码。

交付前只更新内置报告、证据索引和外层签名，不重编已测业务代码。`delivery.json` 记录 ZIP 哈希、逐文件解压比对、签名与测试代码一致性；应用只做 ad-hoc 签名。
