## 范围与限制

- 旧/新候选 0.41.0/0.42.0 仅为测试夹具；未打包发行版、创建 Release 或上传安装包。
- 签名更新使用受控 HTTP 传输和真实 Host；跨版本选择测试通过顺序启动两个候选验证数据兼容，不冒充另一轮在线签名更新流程。
- Mac UI 在全新合成 Fabric 实例中真实查询、下载及安装 Fabric API；没有启动游戏或读写个人实例。
- 本轮未重做真人微软登录、皮肤上传、CurseForge 线上认证、独立游戏存活或世界保存。原分支相应历史证据保持原范围。
- 自动更新默认仍需发布者配置可信公钥和源；不提供默认官方频道，不替换 UI，不迁移数据格式。
- 主工作区保留的统一搜索未提交副本不应再次当作新功能重复合并；继续开发应使用已经整合的提交。
