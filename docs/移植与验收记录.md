# PCL Mac Port Preview 0.1：移植与验收记录

日期：2026-10-23，Australia/Sydney。

**首个 Apple Silicon 原版闭环已跑通：官方 Java 21 → Minecraft 1.21.1 下载与校验 → 安装 → 试玩图形启动。用户已确认游戏标题界面正常显示。Modern UI 自包含应用包也已实际打开，并通过解压后的再次启动检查。**

这是第三方移植预览版，不是完整 PCL 功能对齐版；正版登录还需用户提供 OAuth client ID 并完成授权验收。

## 实际代码边界

七个项目组成独立解决方案：

| 项目 | 实现 |
| --- | --- |
| MeloongCore.Shared | 保留 netstandard2.0，26 个 C# 文件中 21 个原样复用、5 个修改；修正 Unix 路径与根目录、IO、链接处理、日志默认路径，添加兼容 CNG 密钥格式的托管 ECDSA 分支 |
| PCLCS | 保留原 9 个源码文件及模型；移至 net10.0、移除 WPF 项目引用，适配 Java 路径、候选目录、架构和路径哈希 |
| Pcl.Legacy | 从 PCL 原 VB 规则逻辑提取平台检查，改为显式 OS/arch/version/features 上下文 |
| Pcl.Core | 元数据、下载/续传/校验、官方 Java 安装、游戏安装、参数生成、进程监督与微软设备码认证；无 WPF/Avalonia 引用 |
| Pcl.Cli | 调用同一核心进行安装、启动与验收 |
| Pcl.Desktop | Avalonia 12.1.4 Fluent/Modern UI，提供安装/修复、进度、日志、试玩及微软登录入口 |
| Pcl.Tests | 可重复的文件、加密、规则和本地 HTTP 故障测试 |

新的下载服务使用现代 HttpClient、限并发、临时文件、Range 续传和校验后提交，替代与 UI/全局状态耦合的旧边界。没有宣称完整移植原 ModNet 的全部调度、分段策略或性能行为。首版也不处理继承版本与加载器安装。

上游来源：PCL `6b9a50df911c9d68b69b24c979efba477fb14b67`；MeloongCore `98157d65c7627721c816c02e8be96ac4fe61d615`。7 个上游文件发生修改（Shared 5 个 + PCLCS 2 个），完整差异见 `upstream-changes.patch`。原始 Shared 源码和前一轮 Windows EXE 的哈希已复核，未修改。

## 安装与游戏启动实测

本机：macOS 27.0.1、Arm64。构建 SDK 10.0.402，应用自带 .NET 10.0.13；Java 来自 Mojang 官方 mac-os-arm64/java-runtime-delta，实际版本 21.0.7、架构 aarch64。

- 下载并校验 Java 的 145 个文件；按官方 manifest 设置执行权限和链接。
- 客户端 JAR 为 26,836,906 字节，SHA-1 `30c73b1c5da787909b2f73340419fdf13b9def88`。
- 安装 63 个支持库、3,888 个去重后的资源对象；客户端/支持库/资源共 3,952 个唯一文件，917,659,814 字节。
- 按官方版本、资源索引和 Java manifest 的 SHA-1/大小逐文件检查，再提交最终文件。
- 采用元数据中的 osx 规则、`-XstartOnFirstThread`、Mac classpath 分隔符和匹配架构的 Java。没有使用 Windows natives 或 WINDOWS-ROOT 参数。
- 实际 Java 进程启动，日志记录 LWJGL 3.3.3、资源管理器、OpenAL 和纹理图集创建；随后出现正常停止日志，退出码 0。
- 用户明确确认“看到了，标题界面正常”。本轮没有进入世界进行游玩或验证服务器连接。

最初的 smoke 判据要求进程在 65 秒末仍存活，因此将提前正常退出标为 needs_review。保留了原始结果；复核记录接受“渲染初始化后正常退出”作为启动通过，并加入用户视觉确认，未修改原始游戏日志。

## 应用包验收

- 生成 `PCL Mac Port Preview.app`，自包含 osx-arm64 发布。
- Modern UI 主窗口实际打开，应用自身视觉树已渲染为 PNG，并检查中文与布局。
- 直接运行包内可执行文件时清除外部 DOTNET_ROOT，主窗口仍正常打开。
- ZIP CRC 检查通过；解压后递归签名检查通过，解压出来的应用再次启动成功。
- 本地 ad-hoc 签名，不是 Developer ID 公证版；没有进行公证或发布到公共下载渠道。
- 应用 ZIP 不包含 Minecraft 客户端、Java 下载数据、SDK 或账号令牌。

`artifacts/启动已验证的游戏.command` 使用本地已安装的数据目录；独立应用包默认使用用户的 `Library/Application Support/PCL-MacPort`，在新位置运行时按需安装。
