# PCL Mac 0.10：搜索、依赖与整合包

本版在 0.9 上继续开发，保留所有历史包与失败证据。功能矩阵仍为 132 项；本轮没有把部分实现或外部条件从范围中移除。

## 多源搜索

侧栏“多源搜索”统一查询 Modrinth、当前实例本地资源，以及提供自己密钥后的 CurseForge。密钥只保存在当前窗口内存。按游戏版本、加载器、资源类型查询，各来源分页独立；本页按带来源命名空间的项目 ID 合并。相同名称不会被自动当作同一项目。

本地包内文件会先检查实际 SHA-1，再通过 Modrinth 官方按哈希查询确认来源，同一项目显示“本地 + Modrinth”。离线模式不请求远端，仍能搜索本地资源。一方网络失败保留其他来源并显示该来源不可用；用户取消向所有来源传播。支持兼容版本选择和带前置安装，Fabric 使用原有 JAR 内声明约束解析器。

无密钥的实际验收为 Modrinth + 本地，不是两个在线商店的实测。CF 接口接入但未用真实密钥验收；尚无可信 MR↔CF 全量项目映射，因此跨商店同名项目继续分开，也不保证跨页全局去重。

## 复杂依赖

`MavenComparableVersion.cs` 将 Apache Maven 3.9.9 的数字/限定词/嵌套列表算法移植至 C#，数值用 BigInteger。按上游规则区分点号和连字符，处理 alpha/beta/milestone/rc/snapshot/release/sp、限定词别名、数字与字符转换、前导零和长整数。对外输入限制为 ASCII、1–512 个非空白字符。

9,721 组确定性用例由实际编译的官方 Java ComparableVersion 生成，再由本版 C# 执行对照；包括上游测试中的版本和随机组合。版本范围补充倒置/空区间、无序重叠拒绝，并按 Maven 将裸版本当作推荐值、`[版本]` 当作精确限制。不是任意 Unicode 字符串或全部 Maven 版本选择机制的等价声明。

Forge/NeoForge TOML 补充 `${file.<属性>}` 展开、默认版本、依赖端与排序声明检查。第三方语言加载器不再错误地与 FML 自身版本比较，会提示由游戏加载器继续检查；完整第三方 language loader/Jar-in-Jar 选择、旧 mcmod.info 依赖和实际 OpenGL 能力仍有缺口，RES-009 保持部分实现。

## 整合包

- HMCL：读取 `minecraft/pack.json`，保留对单个 `versions/*/*.json` 的兼容。能识别官方原版、Fabric、Quilt 的定义或合并定义，读取组件身份，并在转换前与官方定义核对。包内客户端、多版本或无法判定的自定义入口明确拒绝。
- MultiMC：已声明的官方组件补丁可先与官方 MultiMC 元数据核对，匹配后通过现有安装器按 Mac 重建；未知组件、jarmods、顺序/库/启动参数差异不会静默丢弃。
- 显示名称和时间字段不作为行为差异；实际组件、库、参数等必须匹配。压缩包包含多个实例根目录时停止，让用户分别导出。
- 不复制包内 Java 或启动器，不执行包内启动脚本。配置与模组仍走现有 ZIP 路径检查、校验、独立实例和事务流程。

官方定义组合的 HMCL/MultiMC 测试包用于验证转换路径，不代表全部外部导出包兼容。另使用未经修改的 Modrinth Adrenaline 真实发布包验证完整导入与启动，具体版本以回执为准。

- 主工程回归：`artifacts/evidence-0.10/regression-final/test-results.json`。
- 官方 Java 对照源码、编译类和生成记录：`artifacts/evidence-0.10/maven-oracle/`；供离线回归的结果集：`tests/Pcl.Tests/Fixtures/maven-comparison.tsv`。
- 第一候选实际安装成功，但异步进度覆盖成功提示导致验收失败：`artifacts/completion-candidate-0.10/evidence/completion-features-result.json`。已修复进度生命周期，保留原记录。
- 第二候选完整流程：`artifacts/completion-candidate-2-0.10/evidence/completion-features-result.json`。
- 最终自包含 ZIP：`artifacts/completion-final-0.10/evidence/completion-features-result.json` 及同目录 `completion-runtime-cases.json`。
- 源码独立重建、ZIP 校验、签名与最终证据索引：`artifacts/release-verification-0.10.json`。

验收目标为 1.21.1 的 HMCL/Fabric、MultiMC/Fabric、Adrenaline、NeoForge + FerriteCore。游戏和 Java 复用独立复制的已校验缓存，模组及加载器联网获取；每个实例从 GUI 离线启动，观察图形/图集初始化及 45 秒存活，再由测试主动停止。不是冷缓存下载或世界/存档验收，137 退出码是测试停止。以实际回执状态为准，不从预定流程推定通过。

使用与 0.9 相同的 schema 2 设置；不要同时用旧版操作同一数据目录。旧设置备份和回退方法见 0.9 文档。应用为本地 ad-hoc 签名，未公证；只实测当前 Apple Silicon Mac，最低 macOS 14、Intel、真实账户和跨网多人游戏仍未验收。
