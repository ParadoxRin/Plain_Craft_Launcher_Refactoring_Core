# PCL Mac 0.13：搜索分页与实例备份

本轮继续完成无需账号或密钥的功能。应用仍是开发版，完整功能矩阵的缺项保留；Minecraft 应用审核状态沿用 0.12 的已提交记录，本轮没有重新检查审核结果、授权或启动游戏。

## 本轮变更

| 矩阵项 | 实现 | 检查范围 |
|---|---|---|
| RES-003 多源结果去重 | 查询与筛选快照；跨页按来源限定的项目 ID 去重；后续元数据合并到首次出现的页；前后翻页缓存；失败来源重试保留成功来源的快照 | 模拟取消/部分失败/重复整页；实际 Modrinth 两页与已安装资源交叉去重；界面重新查询、安装、关闭在线来源 |
| INST-006 实例备份恢复 | schema 3 逐文件大小及 SHA-256；创建后完整复核；独立的离线校验入口；恢复在临时目录校验和修复，最后登记；偏好与启动设置单次原子保存 | 损坏/缺失/额外文件、路径大小写及 Unicode 冲突、链接、取消、无效设置；真实资源包及存档字节夹具恢复 |
| 资源界面 | 非模组分类隐藏百科和 JAR 导入按钮；修改文字或在线筛选立即清空旧结果，避免旧页继续翻页 | 渲染后的中文界面截图；这是程序驱动的 GUI 验收，不是人工鼠标验收 |

搜索保持各来源自身的分页大小，所以合并后每页项目数可能不同，也可能出现已全部合并的空页；若来源仍有后续结果，可继续翻页。搜索快照仅在当前窗口/查询内保留。重试本页重新请求来源，但已有成功来源的结果保持不变；完整刷新请重新搜索。同名项目不构成跨商店身份依据。

备份哈希用于检测内容损坏，不代表发布者签名。旧 schema 1/2 备份仍可读取，但“校验备份”会明确显示没有逐文件哈希。备份包含实例数据，不包含全部共享资产、Java 或账号凭据；恢复仍需官方网络和可用的对应加载器依赖。这不是跨设备、完全离线的一键恢复。

## 本轮调查后仍保留的缺口

对照 [Quilt 元数据规范](https://github.com/QuiltMC/rfcs/blob/main/specification/0002-quilt.mod.json.md) 与 [Quilt Loader 的 V1ModMetadataReader](https://github.com/QuiltMC/quilt-loader/blob/develop/src/main/java/org/quiltmc/loader/impl/metadata/qmj/V1ModMetadataReader.java)，确认 Quilt 的裸版本范围、any/all、unless、provides 与嵌套候选加载规则不能简单复用 Fabric 校验。当前未加入完整 Quilt 求解器；RES-015 保持部分实现。

后续无需密钥优先项：Quilt 嵌套候选和条件约束、Forge JarJar 完整选择、第三方继承版本与自定义 HMCL/MultiMC 组件、共享依赖齐全的可搬迁备份。CurseForge 在线 API、微软审核、跨网双端联机等仍保留各自外部条件。
