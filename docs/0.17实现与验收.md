# PCL Mac 0.17 实现与验收

日期：2026-10-24（Australia/Sydney）。Apple Silicon，macOS 14+，第三方开发版。

## 账户修复与真实验收

此前主界面只检查账户记录类型，退出登录后保留的微软账户记录仍会让启动按钮可用，直到核心返回“请先登录”。0.17 新增 `HasMicrosoftCredential`，区分保留的账户记录与可尝试恢复的凭据。退出后显示“需重新登录”并禁用启动按钮；启动核心依然独立进行正版验证，这个界面检查不代替权益验证。

使用同一真实正版账户，通过实际“退出”按钮清除钥匙串刷新令牌和内存会话，确认当前管理器、全新管理器都拒绝恢复，强制触发禁用按钮事件也没有启动进程。随后通过实际登录按钮及微软官方网页重新授权，确认账号记录没有重复、正版权益重新验证成功；全新管理器从钥匙串冷恢复并再次验证成功。脱敏结果见 `artifacts/verification-0.17/microsoft-lifecycle-0.17.json`。

用户明确没有第二个可用微软账户，因此真人双账户切换仍待验收。新增两个独立身份的协议夹具，验证选中账号、缓存令牌、client ID、持久刷新令牌、注销及刷新轮换互相隔离；这不替代真人双账号验收。

207 项回归通过，包含新增微软账户隔离测试；解决方案编译 0 警告、0 错误。自有源码类、方法与关键逻辑保留中文说明，嵌套代码按层换行；注释/格式化工具核对语法令牌等价。第三方源码保持原样。当前审计结果复制到 `artifacts/verification-0.17/`。
