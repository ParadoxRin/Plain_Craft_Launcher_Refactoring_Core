# 开发快速开始

目标：从源码运行“最小客户端 → 独立 Host”，无需个人账号、游戏目录或发布签名。下面命令从仓库根目录执行；路径即使含空格也由入口按参数传递。

## 1. 准备环境

需要 Python 3.9+、Git 和 `global.json` 所选 .NET SDK。Unix 构建 Host 还需要 C11 编译器 `cc`；macOS 使用 Xcode Command Line Tools（`xcode-select --install`），Linux 安装发行版的 C 编译工具链。Windows Host 构建不需要该 Unix 辅助程序。

```sh
git clone https://github.com/ParadoxRin/Plain_Craft_Launcher_Refactoring_Core.git
cd Plain_Craft_Launcher_Refactoring_Core
python3 dev.py setup
python3 dev.py doctor
```

Windows 用 `python` 代替 `python3`。setup 优先使用环境变量 `DOTNET` 指定的可执行文件、仓库 `.tooling/dotnet`、PATH 中的 dotnet；尊重 global.json 的 latestPatch 策略。兼容 SDK 已存在时不下载。缺少 SDK 时仅 Apple Silicon 自动调用已有官方 SDK 下载/校验脚本；Windows、Linux 和 Intel Mac 请先安装 [官方 .NET SDK](https://dotnet.microsoft.com/download/dotnet/10.0) 中与 global.json 匹配的版本。

指定已有 SDK（值是可执行文件，不是目录）：

```sh
export DOTNET="/absolute/sdk/dotnet"
# PowerShell：$env:DOTNET = 'C:\sdk\dotnet.exe'
```

doctor 失败会返回非零并说明缺失项。它不还原 NuGet、不验证网络，也不证明 Java、GUI、系统凭据或游戏支持。

## 2. 跑通首次交互

```sh
python3 dev.py test quick
python3 dev.py example
```

example 自动构建 Host 和最小客户端，并打印本次 `artifacts/dev/example-随机值/` 路径。输入：

```text
accounts
exit
```

看到 Host 身份/能力及账户列表后输入 exit，客户端会请求正常关闭 Host。新目录中账户列表可以为空。只有主动输入 install/launch 等命令才会执行相应安装或启动操作，完整操作见 [示例说明](../examples/Pcl.MinimalClient/README.md)。

每次运行创建新数据根，不需要删除旧目录重试；不会选择个人实例。数据和测试结果留在 Git 忽略的 artifacts/dev 中，确认对应进程退出后可自行清理。开发示例保留状态时使用示例文档中的显式 --data-root 命令，勿让多个客户端同时占用同一数据根。

## 3. 选择开发路线

- 客户端：`python3 dev.py build sdk` 或 `build client`；阅读 [客户端接入](客户端接入指南.md)。客户端构建与 Host 构建独立；Desktop 接线及 SDK 导出见 [开发指南](开发指南.md)。
- 核心：`python3 dev.py build core`；按 [功能实现导览](功能实现导览.md) 找入口，再运行 [对应测试](测试指南.md)。
- 协议调试：`python3 dev.py host` 启动全新隔离 stdio Host，stdin/stdout 使用 NDJSON，命令诊断和构建输出走 stderr；普通交互用 example。输入 EOF 正常结束。hello 示例见开发指南，stdio 不等同于可重连私有管道。
- 发布：进入 [发布与维护](发布与维护.md)，再使用既有打包脚本。开发运行不会生成正式安装包或配置更新频道。

## 常见问题

| 现象 | 处理 |
|---|---|
| SDK 缺少或版本不匹配 | 检查 global.json、DOTNET 和 `dotnet --list-sdks`；重新运行 setup/doctor |
| NuGet 还原失败 | 查看实际构建错误，确认网络、代理和依赖源；doctor 不检测 NuGet 可达性 |
| 找不到 cc / Apple SDK | 安装本平台编译工具；本机 Host 构建不等于支持交叉编译所有平台 |
| ATTACH_FAILED / 数据根被拒绝 | 使用入口生成的物理绝对路径；自定义路径参考最小客户端文档 |
| SESSION_IN_USE | 正常关闭拥有该数据根的客户端；使用全新根，不删锁文件夺取会话 |
| quick 成功但业务异常 | quick 只检查仓库结构和夹具；继续运行 core 或 contract |

所有入口默认 Release 构建；帮助：`python3 dev.py --help`、`python3 dev.py test --help`。失败返回非零，条件不足不能算通过。
