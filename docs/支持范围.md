# 支持范围

0.44.0 面向开发者提供 macOS ARM64 轻量 Host、匹配的 Client/Contract SDK 和源码。Host 包需要预装 ARM64 .NET 10 运行时（或 SDK），不包含图形界面、游戏 Java 或游戏文件。跨平台核心构建与自动化测试不代表 Windows/Linux 完整桌面产品已经支持。

| 功能 | 范围与限制 |
|---|---|
| 安装与启动 | 提供原版及加载器安装、任务状态/取消和 Java 管理；版本、Java、加载器、模组需兼容 |
| 账户 | 微软授权、离线/试用遵守授权约束；外置认证账户当前不能启动游戏 |
| 资源搜索 | 统一浏览与 Host 安装事务；CurseForge 在线认证、所有来源及所有模组组合不作全面验证承诺 |
| 光影配置撤销 | 限 Iris config/iris.properties、资源包 options.txt；恢复最后一次应用的配置，外部更改时拒绝覆盖 |
| 光影包卸载 | 仅清单拥有且哈希未变的 ZIP/ZIP.disabled；不删除无归属的个人文件 |
| 光影环境卸载 | 限可信归属的 Fabric/Iris 环境；旧环境、手动文件不追认，Oculus 未覆盖 |
| 加载器调整 | 创建新副本并确认；不承诺任意组合原位替换 |
| 实例导入 | 支持可识别的完整目录和本启动器格式；任意第三方继承链和外部目录原地注册仍有限制 |
| 任务恢复 | 安装事务与工作区写任务分开处理；未知提交状态返回 WORKSPACE_REVIEW_REQUIRED，不能强行重放 |
| 游戏日志 | 独立模式的标准输出/错误由独立辅助进程脱敏限长；模组自行写出的文件不在此范围 |
| 数据更新 | 百科/映射支持签名、兼容、防重放与回退；本版不配置线上 feed，使用内置内容 |
| 应用更新 | 更新实现保留，本版默认手动升级；无生产信任根、无 Developer ID 公证 |

事务具有原子替换和进程退出边界保护，但不承诺抵御硬件断电、文件系统损坏或所有第三方程序并发改写。缺少可信备份哈希的旧回执不能自动补造证明。

功能矩阵用于开发定位，不作为产品完整度百分比；保留矩阵中的缺口，不把未实现功能改名为范围外来宣称完成。正式版发布门槛见 [发布与维护](发布与维护.md)。

## 兼容与接入约束

- 游戏 Java 与运行 Host 的 .NET 是两套独立依赖。Java 主版本按游戏元数据选择，启动前检查真实版本和架构；不能把所有 Minecraft 版本统一套用同一 Java。
- 多实例共享已校验的库和资源缓存，各自保存模组、配置和世界。加载器调整通过新副本完成，不原位覆盖已有实例；备份恢复不会直接激活导入的 Java 路径或附加执行参数。
- 旧版参数、LWJGL 2/3 和 ARM64 原生库通过固定规则适配。未覆盖的历史安装器、原生库和模组组合可能拒绝启动；版本清单可见不等于全版本兼容。映射来源见 [XMCL 来源说明](XMCL参考与Mac兼容性调整.md)与[第三方声明](THIRD-PARTY-NOTICES.md)。
- Mac 光影快捷预设限定 Minecraft 1.21.1，创建独立 Fabric/Iris/Sodium 实例。静态图形能力检查不是完整 GLSL 分析；不能据此保证所有光影在 Apple GPU 上可用。
- OptiFabric 安装服务限定 Minecraft 1.20.1、Fabric 0.16.14、OptiFabric 1.14.3、OptiFine I6，创建新实例并检查冲突。OptiFine 二进制仅在运行时从作者来源取得，不进入发行包。
- 公开下载与微软登录分离。微软授权配置见[配置指南](微软登录开发配置.md)；刷新凭据由 Host 的平台凭据库管理，不随 SDK、实例备份或发布包分发。离线身份不提供微软在线服务授权。
- CurseForge 需要调用方配置合法 API Key；没有分发权限或下载 URL 的文件转为手动获取，不推测 CDN 地址。来源错误与可用性通过协议返回。
- 独立文件下载先校验再原子保存，拒绝覆盖；另存服务端或安装器不意味着执行它。上游校验值冲突应报错，不能静默换用另一预期哈希。
