# Plain Craft Launcher Refactoring Core 支持范围（0.41.0）

目标为Mac/Windows/Linux共享核心和自定义客户端；当前发布与实机证据仍以Apple Silicon Mac为主，Windows/Linux及SwiftUI未验收。

实现状态、支持范围与验收状态分别记录；本文不关闭功能矩阵的条目，也不把未实现改成范围外以减少缺口。矩阵历史分类保持 35 项实现缺口。

| 功能 | 实现状态 | 当前支持范围 | 验收状态及剩余 |
|---|---|---|---|
| 光影配置撤销 A | 已实现安全事务 | Iris 的 config/iris.properties；资源包 options.txt；只恢复最后一次应用的配置 | 38项定向用例与真实Iris流程通过；游戏改写配置时拒绝覆盖；0.35未做世界视觉验收 |
| 光影包卸载 B | 已实现安全事务 | 清单拥有且哈希未变化的ZIP或ZIP.disabled；一次至多128包；混合模组/资源包选择须分开处理 | 真实Complementary包与中断、冲突、取消测试通过；不删除用户文件和目录，不移除环境组件 |
| 光影环境卸载 C | 已实现限定范围 | 新版安装且有可信归属的Fabric/Iris环境；哈希、清单、实际JAR依赖及其他用途共同决定可删除集合 | 22项定向测试、真实UI取消/确认、共享/独占卸载后渲染通过；旧环境/手动文件不追认，自定义Fabric依赖覆盖拒绝；Oculus仍待办 |

0.35 的游戏启动测试证明进程启动、渲染初始化和短时存活，不证明任意光影效果或长期稳定性。Complementary r5.9.3 在1.21.1/Iris 1.8.8日志中有较新生物群系/着色器uniform名称警告，保留该限制。

事务使用刷盘后的同目录原子替换，已验证进程退出边界；没有模拟硬件断电或文件系统损坏。提交前取消不修改目标；预写意图后完成有限文件提交或重启恢复。冲突时保留现场并阻止启动，不假报完成。旧版激活回执缺少备份哈希，拒绝自动覆盖；原备份保留，不能自动补造可信哈希。
