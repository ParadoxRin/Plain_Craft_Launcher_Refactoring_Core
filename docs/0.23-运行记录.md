# PCL Mac 0.23 — 本轮实现与运行记录

本轮以 0.22 为基础，优先补齐本地设置行为、离线皮肤与主页，并删除赞助入口及宣传内容。没有把 14 项全部标为完成：8 项补齐本地行为，3 项采用实际可运行的 Mac 平台实现，3 项仍有第三方兼容或外部实测限制。

## 玩家名皮肤

在真实皮肤窗口输入 Notch，依次点击获取、保存、刷新：官方玩家资料、官方纹理服务均返回成功；保存 PlayerName=Notch、Model=wide，关闭并重开窗口后恢复玩家名和 PNG。皮肤解码为 64×64；导出服务实际写出 PNG；旧版转换解码为 64×32。刷新只在成功取得完整 PNG 后替换保存记录。

随机、Steve、Alex 会同时保存纹理与模型；离线启动按模型调整 UUID。这与原版选择模型时改变身份的思路一致，但更换模型可能影响已有存档中按 UUID 保存的物品、位置和服务器身份，界面已经说明。此轮未进行游戏内人物外观观察。

## 运行中的问题与处理

资源首次安装时，隔离目录没有 Fabric 加载器版本资料，依赖求解拒绝了 Sodium 安装并撤回操作。这是测试目录准备不足；随后复制现有 Fabric 1.21.1 的 profile 元数据到隔离目录，再只运行资源部分，五种格式全部安装完成。没有放宽依赖约束。

本轮还修复了主页刷新打开重复预览窗口的问题，补充无根命名空间的原版 XAML 片段和常见动态颜色引用。未支持的控件明确报错，不伪装成有效入口。

## 交付与执行范围

- 新应用为 PCL Mac 0.23.app，Apple Silicon、macOS 14+，自包含运行时，采用本地 ad-hoc 签名；没有 Apple 公证。
- 保留旧版应用和 ZIP，不覆盖原始参考源码或现有游戏存档。
- 应用、当前源码包不携带历史发布说明中的赞助宣传；上游署名和必要许可证保留。
- 新增功能运行使用隔离数据目录；没有使用微软账号、密钥或原有存档。
- 按用户要求：没有执行历史回归套件、格式审计、包完整性检查、签名验证或人工验收。正常编译、代码签名和新增功能运行照常执行。
- 本记录不代表全部 Minecraft 版本、加载器、微软登录或第三方远程主页在 0.23 上重新通过测试。

机器可读运行结果见本目录的 feature-run-0.23.json、resource-run-0.23.json、fragment-run-0.23.json 和 priority-receipt.json。首次记录中的资源失败由 resource-run-0.23.json 的后续成功记录补充，未删除失败记录。
