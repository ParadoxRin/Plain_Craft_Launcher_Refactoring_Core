# PCL Mac 0.28 · 工作区 Host 迁移

本轮依据现行架构规范 v1.3（延续 v1.2 的边界与生命周期约束） 延续迁移，保留 Avalonia、原安装算法、账户与游戏进程策略。

## 实现边界

- 实例管理、启动设置、图标、复制/导入/修复、备份/恢复/回收站通过 Contract 工作区命令进入独立 Host。
- 本地模组、光影、资源包的扫描、启停、移除、依赖检查、更新、批量准备/提交/放弃、忽略版本与世界数据包均由 Host 执行。
- 整合包预览、可选文件、手动 CurseForge 文件匹配、安装、保留用户改动的副本更新、导出配置及 mrpack 导出由 Host 执行。密钥只存 Host 内存，收据只保存不透明句柄；没有密钥的流程仍可使用。
- 默认在线 Modrinth 浏览器的 Java/Fabric 自动准备、安装、更新、导入、启停、应用/撤销、光影依赖、数据包安装和另存为已移入 Host。搜索目录和显示模型仍使用旧 Core 兼容层。
- InstanceWorkspace、InstanceViewCache、LocalResourcesWindow、PackManagerWindow、PackSelectionWindow 不引用 Core 业务类型；编译符号守卫覆盖它们及嵌套生成类型。组合根负责旧模型转换。
- 客户端只保存受控导出流。Host 不接受任意输出路径；实例和资源写入重新校验当前实例、预览句柄及文件指纹。

## 任务与退出责任

工作区复用 page operationId、同根目录写入队列、受理前落盘、幂等键、取消、状态订阅与会话重连。关闭有任务的窗口会请求取消并等待安全结束；Host 与会话仍由原组合根唯一拥有。页面不释放共享 HttpClient、账户服务或 Host。

新增写入流程采用保守恢复：受理后尚未执行的取消任务可安全续做；已经完成且有私有结果收据的执行返回原结果。写入中断且无法确认是否提交时拒绝自动重放（WORKSPACE_REVIEW_REQUIRED），保留现场并提示核对后重新发起。**这不是所有工作区操作的任意断点续做。** 批量预览属于 Host 会话，Host 重启后需重新准备。

## 未完成范围

Desktop 整体仍引用 Core；UnifiedSearchWindow、CurseForge 专用页面、部分设置/外观等旧入口尚未全部迁出。没有宣称完成全部页面迁移或最终程序集隔离。搜索目录的全量 Contract DTO 化仍是后续工作。

本轮不对未实际登录的第二微软账户、无密钥的 CurseForge 在线 API、未运行的其他加载器或世界保存操作作验收声明。发布采用本机 ad-hoc 签名，不是 Apple 公证发行。
