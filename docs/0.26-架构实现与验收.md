# PCL Mac 0.26：页面契约与可重连 Host

本次保留 Avalonia、账户存储、钥匙串作用域和原安装流程，推进架构规范的增量迁移。它不表示所有旧页面已迁移或全部 PCL2 功能已完成；0.25 及更早归档保留。

## 已接线

- 调整加载器、下载文件两页的构造参数、字段、异步回调只使用 Contract 的显示 DTO 与接口。组合根适配器调用原 `InstanceComponentService` / `ArtifactDownloadService`，保留预览指纹再校验、新副本、备份、收据、取消和官方 SHA-1 校验。内部计划与下载 URL 不暴露给页面，使用适配器范围内的不透明选择 ID。
- 本批这两页仍在 Desktop 程序集中，并通过排他兼容写入授权运行；并未迁成 Host RPC。构建后 IL/签名守卫覆盖页面及编译生成的嵌套类型，拒绝重新引用任何 Core 实现类型。其余旧页面仍在迁移清单中，Desktop 的 Core 引用尚不能删除。
- 默认桌面通过当前用户私有命名管道连接常驻 Host；stdio 保留给原 CLI/兼容测试。数据目录锁仍由 Host 独占，断线不会取消安装、注销账户或终止游戏。
- 客户端身份包含随机会话标识、原 UI 进程身份及启动时间。仍存活的 UI 拒绝第二客户端；断线重连保留原兼容授权。托管游戏返回 Host 持有的逻辑会话身份，不按裸 PID 接管 Java。
- 安装/启动终态和游戏退出使用有界订阅；安装进度通过订阅展示。先登记本地缓冲、再订阅、再取权威快照；重连恢复订阅并按序号去重。客户端空闲时也有由会话持有的重连任务，释放时取消并等待。
- 状态与阶段变化使用 128 条有界队列，进度按 50ms 合并；慢消费者触发断线与快照重同步，后台持久化不等待网络。每连接最多 64 个订阅。客户端也限制 128 条缓冲，重同步保留已交付水位并丢弃失效的未消费缓冲。断线期间不能保证交付每一个中间事件，权威快照保证当前状态收敛。

## 平台与安全约束

使用 `CurrentUserOnly`，另显式设置私有目录 0700、socket 0600。采用短绝对路径，避免 macOS 临时目录超过 Unix socket 路径限制。无 TCP 监听、不将微软令牌放入连接协议、参数或握手文件。此显式权限处理依据 [.NET 官方文档](https://learn.microsoft.com/en-gb/dotnet/core/compatibility/core-libraries/11/namedpipeserverstream-unix-permissions)：.NET 10 在连接时校验用户，Unix 文件权限自动收紧属于后续版本行为。

旧 UI 意外退出且仍持有兼容写入授权时，Host 返回 `LEGACY_RECOVERY_REQUIRED`，不凭 TTL、UI PID 退出或锁文件残留擅自接管可能仍在写入的子进程。这是已知限制。完整 Host 崩溃后的任务续做仍沿用 receipt 与校验流程；本批“重连”主要指原 Host 仍存活的连接恢复，不承诺在 Host 崩溃后恢复游戏托管。

## 本批实际测试

证据目录：`artifacts/architecture-0.26/`。平台测试在隔离目录运行，不注销用户的真实微软账户。

- `session-live.json`：真实安装期间断线、重连同一 Host、终态订阅、水位递增、第二客户端拒绝、空闲自动重连；实际启动 1.21.1 后断线，确认同一 Host/游戏 PID，图形初始化，再主动停止并通过退出事件归还写入授权。
- `pages-live.json`：真实组件预览与副本创建，源文件/副本标记均保留，备份及收据存在，成功计划拒绝重复使用；官方客户端 JAR 下载校验，取消不留目标文件，两页在真实 Avalonia 窗口中打开。
- `client-boundary.json`：Client 无 Core 引用、真实 Host 握手、分页、协议错误与 stderr 隔离。
- `guard/`：合法项目通过；违规符号、项目引用及手工 DLL 引用被拒绝；只引用 Client 的消费者不能编译 Core 构造调用。

测试发现并修复：Broken 状态的管道 `IsConnected=false` 仍需 Disconnect 才能再次接受连接；损坏连接释放时 Flush 抛错不能触发整个 Host 退出；首次订阅和初始快照之间断线需要重试同一订阅；定时重连检查不能无限积累 WaitToRead 任务；恢复同一游戏时只能创建一个拥有退出观察任务的客户端会话。

首次微软测试在钥匙串读取处等待，停止测试后释放数据目录，失败尝试保留。用户确认已允许钥匙串访问后，使用同一 0.26 包内 Host 复测，五项检查全部通过。没有注销或移除用户账户。本次验证已记住账户的恢复、授权刷新与正版启动；未重新执行网页交互登录，也未执行人工进入世界、保存和重进。

图形初始化只证明游戏到达渲染阶段；本批不将主动停止记为正常菜单退出，也不把它当作进入世界、保存和重进的人工验收。
