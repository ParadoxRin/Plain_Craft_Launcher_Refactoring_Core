# 0.33 功能矩阵逐项证据与剩余清单

已审查132项；77项直接关联0.24–0.32的具体测试断言、文件和SHA-256。其余保留既有证据和适用范围，不以缺少新记录推定没有实现。

本轮实际补齐 **INST-010 离线启动脚本**，不是状态调整。新增测试范围见 `audit033.newEvidence` 以及 `0.33-架构实现与验收.md`。

| 类别（互斥） | 项数 | 含义 |
|---|---:|---|
| 已覆盖限定范围 | 42 | 已有证据覆盖声明范围，不代表任意组合等价 |
| 实现缺口 | 35 | 有明确缺失或未完成的行为 |
| 定向验收 | 46 | 已有实现，仍缺指定场景的直接验证 |
| 外部条件验收 | 9 | 需要额外账户、密钥、双端环境或不可得信息 |

外部条件还可能与代码缺口交叉；完整标记在 requiresExternalCondition。没有把46项待验收都算成缺少功能，也没有把一个报告中的断言数量算成已完成功能数量。

优先顺序：不需要密钥的明确实现缺口 → 同类用例的定向验收 → 具备外部条件后补测。UI和远程服务未覆盖范围在逐项表中保留。
