# PCL Mac 0.14：Quilt 依赖、JarJar 与自定义整合包

这是按功能矩阵继续补齐的 Apple Silicon 开发版，仍不代表 PCL2 全部功能完成。下载、安装和本地管理不需要账号或密钥。微软状态沿用 0.12 的已提交审核记录，本轮没有查询审核结果或启动游戏；未经正版权益验证的启动仍被阻止。

## 实现与入口

| 功能 | 本版实现 | 入口 |
|---|---|---|
| Quilt 本地依赖图 | 有界加权布尔求解，顶层必选、嵌套候选择版、循环依赖、版本 any/all、依赖数组 OR、breaks 数组 AND、optional、unless、带组名的 provides、客户端环境、load_type；读取实际加载器的内置依赖 | 资源安装、启停、删除、更新、包安装和启动预检 |
| Quilt 在线前置 | 根据远程项目关系下载并检查实际 JAR；冲突时回溯前置版本，保留精确版本锁定；同时检查现有受管理和手动放入的模组 | 模组资源页、统一搜索、命令行、单项更新 |
| Forge/NeoForge JarJar | 合并所有同坐标的 Maven 范围，选择兼容嵌套文件；未选中模组不参与依赖校验；处理嵌套纯库、顶层身份覆盖、同版本不同字节和未选中损坏 TOML | 本地资源 → 检查依赖关系，以及资源/整合包事务 |
| FML 服务库外壳 | 先按 FMLModType 识别 LIBRARY/LANGPROVIDER/GAMELIBRARY；外层携带的 TOML 不再错误覆盖实际内嵌模组 | Sodium 等服务库包装的资源导入/安装 |
| 自定义 MultiMC | 标准组件仍对照官方元数据；额外自定义组件支持 formatVersion 1、order≥100、requires/conflicts 的 uid/equals，以及附加校验库 | 整合包管理 → 检查内容 / 安装为新实例 |
| 自定义 HMCL | 官方入口和标准参数保持等价时，保留附加的校验 Java 库及 -Dpack.* / -Dmodpack.* 属性 | 整合包管理 |
| 自定义包往返 | PCL 扩展清单保留自定义库和限定属性；安装时下载校验，正确写入共享或 Forge 私有库目录；导出再导入保留 | 导出 .mrpack / 导入 |

Quilt 的版本比较不能直接复用 Fabric：裸语义版本与 `^`（包括 0.x）、`~1`、空预发布后缀、超长数字和原始版本字符串均单独处理。原始版本比较按 FlexVer；官方版本行为对照固定为 Quilt Loader 0.27.1。

自定义 Java 库必须给出 Maven 坐标、普通 HTTPS 地址、SHA-1 和大小；只追加，不替换标准库或原生库。下载落在 `pcl-custom/<sha1>/…`，避免相同坐标覆盖共享缓存。校验值不代表发布者签名。附加库仍是随游戏加载的第三方代码。

MultiMC 的自定义补丁支持 `libraries` 或 `+libraries`，不同时使用；没有虚构 `+jvmArgs` 格式。PCL 的扩展清单不是 Modrinth 通用标准，带自定义组件的导出包应由 PCL Mac 0.14+ 重新导入，不能保证其他启动器保留扩展。

## 实际验收与证据边界

- 回归结果：`artifacts/verification-0.14/release-tests/test-results.json`。包含真实 HTTP 下载夹具、回溯到较旧前置、锁定版本冲突、嵌套循环/别名、180 个候选、启停/删除失败回滚、JarJar 范围交集、服务库外壳、自定义库规范化及导出保留。
- 官方 Quilt Java 实现：1,140 组版本条件逐项对比，无差异。参考数据随源码保存在 `tests/Pcl.Tests/Fixtures/quilt-0.27.1-ranges.tsv`，驱动为 `QuiltRangeOracle.java`。这证明所列版本条件，不等于整个 Quilt 插件 SAT 引擎逐行为等价。
- 官方 NeoForge JarJarSelector 0.4.1：交集择旧版本、无解范围、真实 Sodium 五个嵌套 JAR 的 SHA-256 对比。回执 `artifacts/verification-0.14/oracle/jarjar-comparison.json`。身份覆盖的额外规则由本地夹具验证，未等同全部 FML 模块发现过程。
- 真实 Quilt：1.20.1 + Quilt 0.27.1，下载 QFAPI 7.7.0 / QSL 6.3.0 / Fabric API 0.92.2，Modrinth 发布 `s8dfz9Xa`；92 个候选（含内置项）中选出79个非内置候选，完成导入、依赖检查与启停。
- 真实 NeoForge：1.21.1 + 21.1.264，导入 Sodium 0.8.13（发布 `uMOpc5uV`）及 Cloth Config（发布 `izKINKFg`），检查 Sodium 五个 JarJar 文件、FML 和 Java 约束。
- 自定义包：依据官方 1.21.1 版本描述构建可审计 HMCL/MultiMC 测试包，真实下载 Apache Commons Collections 4.4，校验来源哈希；安装、生成参数、导出、重新导入后核对文件/属性。另在真实 NeoForge 实例副本核对私有库路径。它们是构造的兼容性夹具，不是任意第三方整合包的广泛验收。
- 实际 Avalonia 窗口：在线查询并安装 QFAPI，点击 Quilt/NeoForge 的依赖检查，预览并安装两种自定义包，保存截图和结果。这是程序驱动界面测试，不是用户人工点击或游戏画面验收。
- 最终 ZIP 的自包含应用另行解压后，在新隔离目录重复界面验收；最终结果和包哈希汇总到 `artifacts/release-verification-0.14.json`。旧包、原始归档和用户运行目录保留。

真实文件验收入口：

```sh
.tooling/dotnet/dotnet tests/Pcl.Tests/bin/Release/net10.0/Pcl.Tests.dll --dependency-live <隔离缓存目录> <已校验测试JAR目录>
```

目录需预先包含可校验的 1.20.1、1.21.1 官方缓存、ARM64 Java 与 NeoForge 实例副本。测试会访问官方元数据、Modrinth/Maven 并写入该隔离目录，不执行 Minecraft。

## 保留的缺口

1. Quilt 自定义加载器插件、依赖覆盖配置、JSON5、Fabric schema 0，以及完整官方插件求解器等价性尚未完成。optional/unless 按元数据条件建模；尚未逐版本实测官方求解器对这些条件的所有组合。候选优化权重和原始版本区间的复杂交并行为仍需更多官方引擎对照。矩阵保持“部分实现”。
2. Quilt 远程求解仅覆盖远程清单中已声明的项目关系；不会猜测模组 ID 对应哪个下载项目。单次最多256种组合、每项目64个适用发布、512个下载候选；达到预算会明确停止，不能当作“已证明不兼容”。本地求解限制为6000变量、60000规则、250000搜索节点或10秒；不满足预算不会宣称兼容。批量更新尚无跨所有根项目的联合择版。
3. JarJar 支持范围求交、选择与声明式模组校验；各历史加载器的同版本取舍、module-info 模块身份、语言插件、NeoForge provides 等全部 TOML 语义尚未完整覆盖。同坐标同版本不同字节会拒绝，不随机取一个。Mac 图形/原生二进制兼容仍需运行游戏确认。
4. 自定义入口、客户端 JAR 替换、jarmods、任意 JVM 注入、原生库覆盖和第三方组件安装器仍不支持，明确停止而非静默丢弃。标准组件的非等价修改也停止。
5. 本轮没有登录成功、启动游戏、进入世界或光影渲染的新证据；不能把安装和依赖检查升级为游戏运行验收。
