# PCL Mac 0.18.1 实现与验收

日期：2026-10-24（Australia/Sydney）。本版修复复制或恢复实例的启动参数，不表示所有加载器世界验收完成。

## 修复

NeoForge 21.1.264 测试副本启动时出现模块重复导出错误。复制实例会生成新 ID，但客户端 JAR 保留原文件名；上游 `${version_name}.jar` 排除项因此找不到实际 JAR。

启动计划现在仅在 JVM `-DignoreList=` 中，将当前实例 ID 对应的完整 JAR 名绑定到实际客户端文件名；保留其他排除项、其他 JVM 属性及游戏版本参数。无需改动用户 JAR、重下载或重建实例，也适用于已经存在的复制/恢复副本。

依据：[BootstrapLauncher 官方说明](https://github.com/McModLauncher/bootstraplauncher/blob/main/README.md)规定排除项匹配类路径文件名，未排除的 JAR 参与模块构建。
