# PCL Mac 0.15：Quilt 覆盖与源码说明

本版继续补齐无需账号或密钥的功能。仍为 Apple Silicon 开发版，不代表 PCL2 全部能力完成。微软申请状态维持“已提交，未确认审核结果”，本轮不启动游戏、不重新申请权限。

## 功能与实际入口

- **Quilt 依赖覆盖**：读取实例 `config/quilt-loader-overrides.json`，支持 schema 1、精确 `id`、`depends`/`breaks` 的 `add`、`remove` 和 `replace`/`with`。按官方“替换 → 移除 → 添加”顺序处理集合，保持候选元数据不可变。已匹配、未匹配和未找到旧依赖的情况会在“本地资源 → 检查依赖关系”显示。
- **统一预检**：在线 Quilt 安装、资源启停、整合包导入及启动预检使用相同覆盖逻辑。配置中的未知语义明确停止，不能静默忽略。
- **批量更新**：覆盖配置进入暂存快照及提交前哈希检查；用户在预览后更改配置会阻止提交。Quilt 暂存验证读取原实例的加载器库，避免因暂存层级不同而误报缺失；模组与覆盖配置仍从暂存目录读取。配置只用于比较，不随资源目录提交覆盖回去。
- **生产环境元数据**：Quilt Loader 0.27.1 明确禁止在普通游戏中使用 `quilt.mod.json5`。本版在导入、扫描和递归预检中给出具体错误，即使同一 JAR 同时有 JSON/Fabric 元数据也不会绕过。`quilt.mod.json` 和覆盖文件按严格 JSON 读取。
- **源码说明**：自有 C# 类、方法及块结构加入中文说明，关键依赖算法和事务补充人工解释；VB 规则桥接与 AXAML 布局也添加说明。自动结构说明与人工算法说明区分，详见 `代码注释说明.md`。

## 验证结果及边界

- 回归结果：**205/205 通过**。回归证据：`artifacts/verification-0.15/release-tests/test-results.json`。新增覆盖操作顺序、不可变候选、版本区间身份、数组顺序、optional/unless、未知选择器、严格 JSON、符号链接边界与启停回滚。
- 官方对照：直接使用 Quilt Loader 0.27.1 的 `QuiltOverrides` 与 `StandardQuiltPlugin.replace`，八组集合变换全部通过。相同夹具随源码保存在 `tests/Pcl.Tests/Fixtures/quilt-overrides`。该范围不代表整个 Quilt 插件求解器等价。
- 对照发现并修正：`>=21` 与 `>=21.0.0` 虽然排序边界相等，官方覆盖对象相等性仍区分原始版本字符串。实现保留这一差异，不把替换条件扩大匹配。
- 真实 Mac 界面：通过实际 Avalonia 控件查找并安装 Modrinth QFAPI 发布 `s8dfz9Xa`，实例为 Minecraft 1.20.1 / Quilt 0.27.1。检查有效覆盖，拒绝 Java >=99 条件，恢复配置后成功；随后验证批量预览配置变动被拦截、重新预览提交成功，导出 `.mrpack` 再导入并核对配置字节与依赖检查。
- 上述界面测试由程序驱动，截图中中文可读；不是用户人工操作验收。Java/Minecraft 公共缓存复用已校验文件，QFAPI 在新实例实际下载。没有新游戏启动、世界或光影渲染证据。
- 最终 ZIP 另行解压并在新隔离目录重复验收。发布哈希及回执见 `artifacts/release-verification-0.15.json`。原始归档、0.14 包和用户游戏目录不改动。

## 保留缺口

1. Quilt 覆盖暂不支持 `path`、Java `pattern` 正则、`version`、同一 id 的多条规则、链式替换歧义，亦不对 Fabric 候选应用 Quilt 覆盖。遇到这些配置明确停止。没有加入任意覆盖编辑器或自动放宽模组依赖。
2. Quilt 自定义插件、Fabric schema 0、跨所有根项目的联合远程择版、全部官方依赖区间等价性尚未完成；矩阵保留“部分实现”。JSON5 是官方生产限制，不再作为应直接加载的缺失能力。
3. Forge JarJar module-info、任意自定义包入口及全部历史加载器行为等 0.14 缺口仍保留。
4. 源码中的结构说明基于 AST 自动生成，关键算法有人工说明；不能把注释覆盖率视为所有算法都已人工审计。编译、测试与实际运行证据另计。
