## 1. 实际调用链

```text
App
  -> Composition.Create（一次取得数据目录锁、组装服务）
  -> MainWindow（注入 Contract 接口）
       -> 主界面 InstallButton / 版本窗口“下载并安装”
       -> IVersionInstallService.InstallAsync
       -> VersionInstallService
       -> 现有 InstallOperations.InstallAsync
       -> 现有 VersionInstaller.InstallAsync
       -> 原元数据、下载校验、Java 与加载器流程
```

新安装不再由两个窗口入口各自创建 `InstallOperations`。已安装实例的修复仍走原 `InstanceManager.RepairAsync`。本轮没有搬动版本匹配、下载、依赖求解或安装器内部逻辑。

## 2. 文件与职责

| 文件 | 本轮实现 |
|---|---|
| `src/Pcl.Core/Contracts/Installation/IVersionInstallService.cs` | 同进程接口、请求／目标／进度／结果／错误 DTO；没有 operationId 或 RPC 受理语义 |
| `src/Pcl.Core/Application/Installation/VersionInstallService.cs` | 校验版本、加载器及目标，拒绝并发／退出后的新安装，映射进度与错误，追踪活动调用并协调停止；真实转发旧安装门面 |
| `src/Pcl.Desktop/Bootstrap/Composition.cs` | 创建一次共享 MinecraftService、安装门面与生命周期作用域；在独占数据锁下执行启动中断标记 |
| `src/Pcl.Desktop/Bootstrap/InstallationLifetime.cs` | 等待安装与 UI finally 完成；有界等待，单次共享资源释放；超时保留依赖和锁 |
| `src/Pcl.Desktop/App.axaml.cs` | 唯一启动组合根，注入应用接口；退出等待预算为五秒，超时走最终进程退出，不释放仍在使用的依赖 |
| `src/Pcl.Desktop/MainWindow.axaml.cs` | 主安装入口调用接口；跟踪 RunAsync 收尾；关闭时协调取消；窗口不再释放共享 MinecraftService |
| `src/Pcl.Desktop/VersionManager.cs` | 版本下载窗口安装调用同一 Contract 接口，保留原加载器选择 |
| `tests/Pcl.PhaseOne.Tests` | 本轮针对性控制台测试，包含替身生命周期及独立子进程真实锁争用 |
| `src/Pcl.Desktop/PhaseOneSmoke.cs` | 显式测试标记下驱动真实按钮和关闭路径；普通启动不运行测试 |

内部委托测试接缝只用于替换安装执行以控制取消与收尾时机；生产组合根使用 `InstallOperations + MinecraftService` 的真实构造路径。没有 DI 容器、全局 Composition 单例或新 Kernel。

## 3. 关闭与所有权

- 组合根拥有共享 MinecraftService 和根数据锁；窗口借用共享服务，拥有自己的 Fabric、资源目录、认证与图像等展示相关对象。
- 应用退出先停止新调用并请求取消，等待实际安装结果和主窗口 RunAsync 的 finally。
- 只在排空后释放共享服务，再释放数据锁。窗口自己的清理有重复入口保护，共享 MinecraftService 已从旧 `Closed` 清理代码移除。
- 生命周期日志最后写入 `root-lock.releasing`，然后关闭该日志写入并释放根锁；释放后不会再向该目录追加生命周期事件。
- 超时不会伪造取消／中断终态，也不会先 Dispose 网络对象再让安装继续。当前同进程应用在超时后以退出码 2 结束，保留原安装历史，由下一次取得锁的组合根处理遗留中断。
- 游戏运行时普通关窗仍隐藏窗口，独立游戏的原启动策略不变。本轮没有重新测试游戏启动及进世界。
- 系统终止通过 Avalonia 公开的 `WindowCloseReason.OSShutdown` 进入零预算、尽力停止路径。本轮只用替身验证其零预算资源处置，没有实际关闭或注销用户的 macOS。

五秒是程序等待任务的预算，不是磁盘提交时间的保证。跨进程后台存活、完整持久化 runner 和恢复协议仍属于后续阶段。

### 十一项针对性测试

结果：`artifacts/architecture-phase-one/tests-targeted/results.json`，11 项通过，0 项失败。

1. 请求、进度和结果完整转发。
2. 无效参数及不匹配目标在后端执行前拒绝。
3. 网络异常映射成稳定代码，原异常文本不进入结果。
4. 未收到取消请求的 TaskCanceledException 映射为 TIMEOUT，而非用户取消（替身异常场景，未注入真实网络超时）。
5. 已取消调用不进入安装。
6. 并发安装拒绝；退出后拒绝新任务；已成功结果不被迟到取消覆盖。
7. 退出等待安装取消清理与 UI finally，重复关闭只释放一次，锁最后释放。
8. 非协作安装超时仍保留活动依赖，之后真实完成才释放。
9. 系统零等待预算不会释放活动任务依赖（替身场景）。
10. 诊断订阅异常不丢失安装结果或阻止停止。
11. 真实数据目录锁：同进程和独立子进程均不能取得已占用的锁；释放后，即使锁文件残留，子进程和新作用域均可取得锁。

```bash

DOTNET_CLI_HOME="$PWD/.cache/dotnet-home" ./.tooling/dotnet/dotnet run --project tests/Pcl.PhaseOne.Tests --disable-build-servers -- "$PWD/artifacts/architecture-phase-one/tests-replay"
```
