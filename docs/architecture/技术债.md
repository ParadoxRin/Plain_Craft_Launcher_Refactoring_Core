# 核心平台架构技术债

## 0.41.0 当前入口

当前定位为三平台共享核心与可替换UI，详见v1.5.1规范。DEBT-002/003按0.32/0.40证据关闭既定范围，不恢复旧桥接。以下按版本排列的记录是历史，不能把“当时尚未迁移”当作当前未完成。

新增/保留：Windows/Linux剩余平台组合、真人账户联调、进程/路径适配；非.NET客户端与契约一致性工具；稳定SDK发布；Core剩余技术执行职责按用例继续整理。CLI历史直接Core调用需在未来提供统一SDK时审视，不给Shell开例外。所有平台均需真实运行证据。已发现的21个不同历史证据缺失路径见收尾第五批，不补造文件。

三系统 CI 已在提交 `497cdd1` 各报告235/235：Windows 原六项已修复，含目录链接目标保护、缓存回收/恢复及平台专用预期；增加四项安全测试，见[本轮验收](../Windows-CI六项修复与验收.md)。原失败证据仍见[历史核对](../CI与文档一致性核对.md)。这不代表所有路径/权限场景已适配，也不关闭平台登录、Java/natives、UI与游戏验收。

## main：系统凭据与平台选择

已落地宿主平台工厂、Windows Credential Manager 与 Linux Secret Service，Mac 保留原 service 和适配器；普通 CLI 与页面备用入口一并接线，见[实现与验收](../三平台凭据与组合根验收.md)。不要继续将“没有 Windows/Linux 系统凭据实现”列为未实现。真人认证/皮肤、其他 Linux Secret Service、Windows 超长凭据方案、Windows 独立进程、Java/natives、图形游戏与平台发布仍待完成；本轮不修改功能矩阵标签。

## main：最小客户端接入

已增加 examples/Pcl.MinimalClient 和 tests/Pcl.MinimalClient.Tests：独立客户端输出只包含 Client/Contract/示例，真实 Host 契约及 Mac 安装取消、重连、崩溃恢复和试玩启动验收见[记录](../最小客户端与Host契约验收.md)。不再将缺少可运行的 .NET 最小示例列为待办。非 .NET 示例、跨语言 schema/一致性工具、稳定 SDK、旧 CLI 改造及 Windows/Linux 真人凭据联调/游戏适配仍保留。
