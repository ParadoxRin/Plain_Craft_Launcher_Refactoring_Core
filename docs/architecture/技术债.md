## 0.33 增量

- 保持 Desktop → Contract/Client 的已完成边界；新增离线脚本窗口只提交实例ID和离线名称，执行复用Host原服务。没有引入新的Core直接依赖或公共令牌DTO。
- 历史功能证据已逐项回填132项，明确区分实现缺口、定向验收和外部条件。完成离线脚本真实导出与独立运行；完整清单见 [0.33剩余项](../0.33-证据回填与剩余清单.md)。
- DEBT-002维持已关闭，DEBT-003与其余已知功能债务不因本次打包关闭。

## 0.32 增量

- Desktop、MainWindow、旧辅助页和 Bootstrap 只引用 Contract/Client；Core/Application 项目和运行时引用已移除，Host 仅为打包构建依赖。新包顶层不存在 Core DLL，业务程序集只随 host/ 子目录发布。
- 任务、日志、选中实例、窗口尺寸、拖入和通知经 Host 处理；账户/皮肤和安装流程复用原服务。旧 desktop.acquire/release 接口及兼容写入授权已移除，历史探针移出生产目录。
- DEBT-002 的依赖移除退出条件已经落实；实际运行证据和范围见 [0.32 报告](../0.32-架构实现与验收.md)。这不关闭 DEBT-003，也不将未测试的功能标为完整。

## 0.31 增量（历史）

- 主窗口版本目录、加载器执行、Mac 配置、OptiFabric 校验安装迁入 Host；微软登录通过 IAccountLogin 接口调用原流程。联机与 OptiFabric 窗口只用 Contract/Client，新增符号约束及主窗口指定处理器的执行器禁用检查。
- EasyTier 由 Host 持有，客户端重连保留；房间秘密只在内存与私有 RPC 中传递。窗口关闭等待任务并断开房间，Host 退出清理所有房间；游戏独立运行策略不变。
- 本机双节点真实 TCP 往返已验证；跨互联网和两位玩家实际进入世界仍未执行。Host 重启不自动恢复临时房间。
- DEBT-002 保持开放：剩余 MainWindow 展示模型、其他旧页/测试模式、Bootstrap 桥和兼容写入授权尚需迁移。不能删除 Desktop → Core，也不将该债务标为完成。详见 [0.31 报告](../0.31-架构实现与验收.md)。
